# 二期「客户与业务」

## Why

现在任务和日志可以记录内部工作，但无法按客户查到参访、订单、服务交接和权益。二期增加公司内部 CRM，App 处理服务，Web 管理商城模拟导入、财务、员工合同和授权。

## What Changes

- Android「公司」默认打开日历，保留原底栏和日历工具；「客户与业务」提供客户档案、服务登记、跟进、交接、已完成观演的年卡核销及更正。
- Web 按岗位开放模拟 CSV 导入、客户查重复核、营收和流水、员工合同；系统管理员只分配模块权限。
- 后端保存客户、责任人、参与人、订单、流水和合同，按组织层级和岗位权限判断可见内容。

## Impact

用 V30 增量迁移新增 CRM 表，沿用一期账号、任务和通知。无真实商城连接、在线支付或合同签署。
