# Change: sprint-0-baseline

## Why

实训 Sprint 0 需要建立可协作的工程基线：明确 MVP、核心能力规格、技术方向与可追踪任务，以便 Sprint 1 实现「登录 → 写日志 → 面板可见」首条链路。

## What Changes

- 初始化仓库目录（android / web / backend / docs / openspec）
- 冻结第一阶段范围与角色简化策略（三档角色起步）
- 建立 auth、work-log、task、panel、calendar-view 等能力规格草案
- 列出 Sprint 0～1 可执行任务清单

## Impact

- Affected specs: auth, work-log, task, panel, calendar-view, theme-nfr
- Affected code: 尚无业务代码；本 change 以文档与规格为主
- Out of scope: AI 地图、MBTI、容器化公网部署
