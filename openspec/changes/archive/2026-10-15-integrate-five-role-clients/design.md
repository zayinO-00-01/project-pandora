## Context
详见 docs/整合计划-2026-10-15.md。当前分支保存 main 合并基线，选择性引入 yukino Android 资源，不引入历史预览或二进制交付物。

## Goals / Non-Goals
本轮打通五角色、日志日期限制、直属查看审批和任务闭环。保留视觉，不扩展十大事、备注、资料、任务邀约或云部署。

## Decisions
- ADMIN 仅管账号；FOUNDER 全公司业务范围；部门和团队领导按实际下级树，员工仅本人。停用账号旧 JWT 失效。
- 上海 today-7..today 共8个日期可写。历史可读，更新同时校验原日期和目标日期；提交后可编辑并保持提交状态。
- 申请对象仅直属上级，审批只读已提交日志及任务；组织/角色/停用变更使旧授权失效，不能获得派发或写入权。
- 沿用 /users/organization、/view-requests 及 task DTO；Web /admin/users。管理员配置防环和角色层级错误。
- main 的 V3 角色迁移为规范，任务 V4，申请 V5。旧 zayin V3 tasks 需受控升级：先备份，仅识别已知历史，保留数据后调整迁移记录，禁止全局 repair 或删库。
- 用户输入失败保留，同账号服务恢复不虚报成功。

## Risks / Trade-offs
H2 文件升级需停服务和备份；工具先副本预演，再独占并核对原库，原地升级而不以快照覆盖；DDL异常需按备份恢复；手机网络与最终 UI 交由用户做少量手测。测试仅覆盖关键权限、边界和真实闭环。
