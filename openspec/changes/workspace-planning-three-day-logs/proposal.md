## Why
十大事只有只读空页面，月历没有可读安排摘要，员工较多时缺少姓名检索。用户要求日报创建窗口缩短为今天及往前 3 天，并只允许当天日报修改。
## What Changes
- 完善十大事列表、详情、个人新增编辑排序与公司事项个人备注；按账号本地保存，明确未同步，留下接口契约，不实现新后端。
- 月历每格显示安排短标题，选中日期后展示完整安排。
- 在现有授权成员列表添加姓名及账号筛选，不扩展权限。
- **BREAKING** 日报创建允许上海今天减 3 天到今天（包含端点）；更新和提交仅允许日报日期为今天，禁止通过换日期解锁历史记录。同步 Android、Web、API 与边界测试。
## Capabilities
### New Capabilities
- `workspace-planning`: 十大事本地前端、月历摘要与员工检索。
### Modified Capabilities
- `android-log-client`: 三天补录、当天修改。
- `log-demo`: 服务端创建与修改的分离日期规则。
## Impact
Android Compose/ViewModel/本地存储，日志 API 与 Web 编辑器，规格和测试；无新增运行时依赖，不修改事项后端或现有组织权限。

用户最新调整：总览只放公司十大事、公司派发与个人十大事，按主次分配面积；新增位于总览与日志之间的职能页，按角色突出派发任务或待处理任务，次要区域进入成员或上级。搜索仅放组织成员，不放事项；月历行距缩小。
