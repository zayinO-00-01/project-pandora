# 首轮 Web 日志反馈 MVP

## Why

与老师讨论后，团队需要尽早交付能操作的增量，收集反馈。用户选择手机/电脑浏览器优先，目标一周内；最终课程仍包含 Android。旧方案将编辑和上级查询排到后续，且缺少接口与状态一致性，无法直接支持首轮闭环。

## What Changes

- 使用一个响应式 Vue 工程实现员工日志与领导查看，共用 Spring Boot 和 MySQL。
- 首轮仅登录、本人增改查、直属上级只读查询；保存即授权可见，无提交/归档状态。
- 新增直属关系、版本并发校验、统一错误、开发端口及腾讯云部署约定。
- 注册、角色管理、任务、四板块、日周月、Android 实现按后续反馈和课程要求安排。
- 安全性与可靠性作为明确验收属性，演示后记录反馈并重排任务。

## Impact

`backend/openapi.yaml` 更新到 0.2.0，属于未实现契约的破坏性修订；若有人在本地已按旧契约编码，应同步返回结构、字符串 id、列表分页与日志字段。旧 `sprint-0-baseline` 重叠部分被本变更替代，其未来能力不自动废弃。

权威开发入口为 `docs/mvp/README.md`。本次只建立文档与契约，任务尚未实现，不归档到当前产品规格，不声称测试通过或飞书看板已更新。
