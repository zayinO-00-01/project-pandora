# Project Pandora · 智能掌上工作系统

面向企业小组的工作日志与任务协作原型。Android 办理业务，Web 管理账号、员工资料和公司十大事项。目标是本地运行、现场演示；尚未覆盖甲方全部扩展需求。

当前增量：`0.7.0-self-task-approval`。个人十大事项、公司原文和个人备注接通后端，个人页展示本人资料，日志显示秒级录入和修改时间；新增自建任务直属上级审核、创始人免审核，以及日历直接选择年月。完成情况见 [当前验收](docs/MVP验收.md)。

## 本地运行

Windows 在根目录运行 `start-demo.cmd`，保持窗口打开，浏览器访问 `http://localhost:8080`。需要 Java17+、Node18+、Maven，首次构建需要联网。

Android 安装本机构建的 `deliverables/Pandora-MVP-debug.apk`，填写 `http://电脑当前局域网IPv4:8080`。手机和电脑需能互通，校园网不通可使用手机热点。APK 不随 Git 提交，下载源码后需自行构建或另外接收安装包。

| 账号 | 角色 | 使用端 |
|---|---|---|
| admin | 系统管理员 | Web |
| founder | 创始人 | Android |
| leader | 部门负责人 | Android |
| team_lead | 团队负责人 | Android |
| staff | 员工 | Android |

初始密码均为 `demo1234`，组织为 `staff → team_lead → leader → founder`。管理员修改后以实际配置为准；无公开注册。

数据保存在运行后端的电脑 `backend/data/`。别人下载项目并在自己电脑启动，使用自己的数据库。旧库升级先停服；启动器备份并转换已知旧迁移历史，未知历史拒绝转换。不要删除数据库或执行全局 repair。

## 当前功能

- 日志：草稿与提交、历史查阅、上海日期今天及前三天补录；只有今天可修改或提交。历史补录直接提交，随后只读。今天已提交的日志仍可编辑。
- 任务：业务成员可给自己建任务，非创始人经直属上级批准后执行；领导可向实际下级派发，责任人选择待开始／进行中／已完成并填写说明，上级查看；不要求填写百分比。
- 组织：按实际上下级授权查看，直属上级查看需申请、批准，可撤销；他人草稿不可见。
- 公司事项：ADMIN 在 Web 发布、排序、停启，最多启用十条；Android 阅读原文并保存仅本人可见的备注。
- 个人事项：最多十条，新增、编辑、删除和拖动排序；保存到后端，换设备可读取。保留本机未同步内容，旧快照须明确导入，冲突须人工选择。
- 资料与日历：Web 管理员维护档案，Android 本人只读查看；日历支持直接选择年份和月份，展示任务和日志摘要。

Debug 开发预览和公司示例是本地数据，不代表真实账号或公司发布内容。任务邀约／请示、消息提醒和 AI 建议尚未实现。已有云端演示服务，访问地址由小组提供。
