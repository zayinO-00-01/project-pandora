# 0.5.3 整合说明

> 历史版本记录：接口、发布权限、保存方式和日期规则可能已更新。当前以 [验收说明](MVP验收.md) 和 [Android接口](Android接口说明.md) 为准。


来源：本地 0.4.31-work-planning 与同学 0.5.1-state-feedback。新版源码固定为 project-pandora 仓库 main 提交 `4ee52ddf2e22150f241b4ee108538915f36ecae9`。

- 接入新版五角色权限、安卓任务派发、状态反馈、派发草稿恢复、同步失败提示及配套后端、Web 管理端。
- 保留本地个人十大事编辑与排序、公司事项个人备注。这些内容仍只保存在本机，尚未同步后端。
- 按用户要求保留本地月历：日期下方显示任务标题和日志首行的小字摘要。
- 日志允许创建今天及往前 3 天的记录；仅今天的日志可修改，补录历史记录提交后只读。前后端及测试保持一致。
- 保留本地 V1–V4 迁移历史，以 V5 增加五角色字段、V6 增加任务状态；不重写已应用迁移。此迁移编号用于本地旧库，不能直接与上游另一套编号混用。

源码备份：`.tools/integration-051/before/`。升级前数据库备份：`.tools/integration-051/database-backup/pandora.mv.db`。

交付包：`deliverables/Pandora-0.5.3-priorities-restored-debug.apk`，versionCode 37。

已恢复公司与个人十大事的完整页面入口，去除“筹备中”提示，恢复原开发预览的公司事项示例。个人事项支持新增、编辑、删除、搜索和上下排序；公司原文只读，支持个人备注。真实公司事项仍取决于服务器返回，不将预览示例当作真实数据。

本机事项和备注按服务地址及账号隔离。切换 IP 或服务器后，旧数据仍保留在原服务地址下，不自动迁移到另一服务。

验证：后端 53 项测试、安卓 24 项测试、Web 2 项测试通过；Web 与 APK 构建通过。模拟器通过真实后端登录；个人事项新增、列表展示与本机持久化已实测。手机真机和同学签名版本的升级尚未验证。

同学提供的安装包与本地签名不同。手机若安装的是同学签名版本，不能直接覆盖安装本地合并包；应由同学使用原签名重新构建，或先另行完成数据备份与迁移。不要为了安装直接卸载含有未同步记录的旧 App。

本地后端使用 H2，无需额外安装 MySQL。运行 `start-demo.cmd -SkipBuild` 可启动已构建服务。手机连接地址填写电脑当前所在网络的 IPv4，端口为 8080；网络切换后需重新核对地址。
