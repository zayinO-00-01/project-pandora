# 首个日志 MVP 验收

当前目标是能演示 Android → 后端 → Web 的日志闭环。这是内部确定的实现增量，待组员和老师讨论后确认后续工作目标，不代表全部甲方需求已完成。

| 项目 | 当前结果 |
|---|---|
| Android 配置地址、真实登录、本人日志 | 已实现；接口层测试通过，真机操作待确认 |
| 草稿保存、提交、已提交修改 | 已实现；同 ID，提交状态保持，失败保留输入 |
| 首页今日日志、按日查看 | 已实现；读取后端同一记录，日期采用上海时区 |
| Web 查看与刷新 | 已验证领导可看授权员工的已提交日志，刷新显示最新正文 |
| 权限与可靠性 | 后端验证登录、越权拒绝、草稿隐私；数据本地持久化；手机重开和断网体验待手测 |
| 本地可运行交付 | 一键启动脚本、Android 源码、签名 Debug APK 已提供 |

2026-10-08 验证：Android 4 项、后端 8 项测试通过；Web/后端打包及 APK 构建成功，APK 签名校验通过。Android 实际 ApiClient 编译代码在 JVM 连接真实后端，Edge 检查 Web 同步，日志 ID 12 的草稿/提交/修改、首页/按日读取保持同一记录。未使用真机或模拟器执行 APK，安装、点击、局域网及手机端恢复仍待按 [本地演示](本地演示.md) 手测。
