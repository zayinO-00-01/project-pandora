目标版本`0.8.1-teacher-alignment`（50）。在用户上一版575b5ab上整合组员#19–#25；保留用户新增能力，按最新选择统一业务规则。17ae205为此前技术整合稿，本页以下方本轮验证结果为准。

## 当前业务规则

| 模块 | 最终口径 |
|---|---|
| 任务创建 | 全体业务成员可选择全公司有效业务成员，包括自己；所有非创始人创建均由创建者当前有效直属上级批准。待审仅申请人及当前审核人可见，批准后责任人执行 |
| 进度提交 | 仅责任人反馈待办/进行中/完成及说明；非创始人交提交者当前直属上级审批，批准前保留旧状态和说明。拒绝/撤回不改变生效内容，可重新提交。创始人本人作为责任人操作免审，创始人创建给别人的任务不免除执行人审核 |
| 任务变更 | 创建人申请修改定义、当前上级审批；创始人可直接修改他人定义。批准前旧内容有效；编辑时不能更换责任人 |
| 删除 | 用户暂按#22：创始人直接软删；创建人对未开始且符合条件的任务直接删，已开始则走上级审核。保留历史记录，取消相关待审操作 |
| 撤回 | 申请人可撤回创建/内容变更、进度和关键词申请；撤回创建后可编辑并重新送审 |
| 日志 | 上海今天及前三天可创建单日或连续多日记录。创建后24小时内可改/提交，包括历史和跨日；修改不延长时限，起止范围固定，已提交不能退回草稿。草稿仅本人可见，录入和修改时间显示到秒 |
| 日历与工作台 | 月周日历只显示已批准任务及截止安排，日志在独立列表。保留直接选择年份月份、返回今天、标签颜色和四宫格入口 |
| 公司与个人事项 | ADMIN Web发布公司事项；Android完整阅读及本人备注保存/清空。个人十大增删改、拖拽排序、后端同步、版本冲突和离线草稿继续保留 |
| 账号与通知 | 我的默认摘要仅姓名/手机/直属上级；本人档案显式展开。保留头像、改密旧会话失效、站内通知及单条/全部已读。通知需刷新，不是手机离线推送 |

## 手机和Web手动验收

运行`start-demo.cmd`，Web打开`http://localhost:8080`。Web用admin；Android用founder、leader、team_lead、staff，密码均为demo1234。手机填写电脑当前IPv4及端口。安装包路径为`deliverables/Pandora-MVP-debug.apk`，SHA256为`E65142B25F1EF5E0A5255825D18A77DC4B367EAD7C3405DA62EB820D7E1FA5FE`。安装前保留未同步输入。云端尚为旧版，当前APK须连接本轮新版后端测试。

1. staff给自己或其他有效业务成员创建任务，team_lead批准；未批准前责任人不应收到可执行任务。
2. founder派发给staff；staff反馈进行中，页面仍显示旧生效状态并提示待审核。team_lead批准后才变进行中；founder不是这条进度的审核人。
3. staff提交完成，分别试拒绝、撤回、重新提交和批准；拒绝/撤回保留原进度。founder给自己安排任务并反馈应直接生效。
4. 创建人修改内容，由其上级审核，查看拟修改内容；创始人可改他人定义。撤回待审创建后修改再送审。
5. 创建人删除未开始任务；已有执行进度的任务走上级删除审核；创始人直接删除。检查通知、列表和日历一致。
6. 新建历史或跨日草稿，编辑后提交；日期范围不可更改。检查秒级时间。超过24小时的禁止写入由自动化检查覆盖，无需人工等一天。
7. 日历跨年选月份、切换月周日、返回今天，确认仅显示任务；日志独立查看。检查键盘、窄屏、深浅主题与返回导航。
8. 浏览器发布公司事项、保存并清空管理员本人备注；Android检查原文、本人备注隔离。个人清单拖拽同步、退出重登、断网恢复以及旧快照导入按实际情况抽查。

先记录复现步骤与账号，不要往真实云端反复创建测试数据。手机操作结果由用户或同学补充，自动接口与构建不替代触摸验收。
