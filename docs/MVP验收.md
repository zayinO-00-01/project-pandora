# 本地整合版验收（2026-10-29）

版本目标：`0.8.0-team-integration`（49）。本轮整合组员 PR #19–#25 和上周未上传的云端版本改动，原项目与云端数据保留。本页记录当前规则，旧文档中的历史版本规则不作为本轮验收依据。

## 可以演示什么

| 模块 | 当前目标行为 |
|---|---|
| 管理后台 | ADMIN 创建、停启账号，维护档案、角色和直属上级；发布、排序和停启公司十大事项，并保存自己的私密备注 |
| 公司与个人事项 | Android 阅读公司完整正文、保存或清空本人备注；个人十大事项增删改、拖拽排序、服务端同步；失败留草稿，跨设备冲突明确选择 |
| 自建任务 | 所有业务角色可给自己安排任务；非创始人经当前有效直属上级批准后执行，创始人免审；待审和拒绝任务不能反馈进度，不进入执行日历 |
| 领导派发与反馈 | 领导向实际下级派发；责任人选择待办、进行中、完成并写说明，无百分比输入 |
| 后续审核 | 非创始人任务提交完成后等待验收：派发任务由创建人验收，自建任务由当前直属上级验收；创始人创建的任务沿用直接完成。内容变更和已开始任务删除按上级审核流程处理；批准前保留有效内容，拒绝时显示原因 |
| 通知 | 本人站内通知、未读数、单条和全部标为已读；需刷新读取，不是手机离线推送 |
| 标签与关键词 | 创始人维护标签，任务和日志可选；创建人和责任人协作添加关键词，修改或删除他人词条须当前直属上级审核；自有词条及创始人操作直接生效 |
| 日志 | 上海今天及前三天可补录；支持连续多日，起止都在允许范围。只有日期为今天的单日日志可编辑或提交草稿，历史和跨日记录只读；录入及修改时间精确到秒 |
| 页面与日历 | 四宫格总览、任务工作台、月周日视图，保留日志和任务日程，直接选年份月份 |
| 本人账号 | 档案查看、头像与密码设置；改密验证旧密码并使旧登录凭证失效 |

## 本地运行与手机验收

在仓库根目录运行 `start-demo.cmd`；Web 打开 `http://localhost:8080`。Web 使用 admin，Android 使用 founder、leader、team_lead、staff；演示密码均为 `demo1234`。手机填写电脑当前 IPv4 和端口，手机与电脑须互通；模拟器能连接不代表校园网允许手机访问电脑。

安装包在 `deliverables/Pandora-MVP-debug.apk`，SHA256：`EA7463E6C27DC873A667316D7F5353CBE324B2A23CCE1CF1174D3BC9DEF4B341`。覆盖安装前确认签名相同；保留未同步内容。以下触摸体验由手机验收：

1. staff 自建任务，team_lead 批准，staff 反馈进行中再提交完成，team_lead 验收；founder 自建直接生效。
2. 打开通知查看待审任务，检查未读数和标为已读；拒绝后能看到原因。
3. 创始人新建标签，派发任务；责任人添加关键词，申请修改创建人的关键词，再由直属上级处理。
4. 新建今天单日日志，修改、提交；补录历史或跨日日志后确认只读，录入时间显示到秒。
5. 日历直接跨年选月份，切换月周日，检查任务与日志、返回今天和小屏布局。
6. 公司备注保存、清空、退出重登；个人清单增删改、拖拽和同步；断网后恢复能继续保存，其他账号看不到本人备注。
7. 检查头像、账号设置、键盘遮挡、深浅主题和返回操作。修改密码后需重新登录，测试后可改回演示密码。
