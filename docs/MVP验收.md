## 当前业务规则

| 模块 | 行为 |
|---|---|
| 创建 | 全体业务成员可选公司有效业务责任人含自己；非创始人交创建者当前直属上级初审。待审仅申请人/有效审核人可见，批准后执行 |
| 进度 | 仅责任人反馈状态和说明；非创始人交本人当前直属上级审批，批准前旧进度有效；支持拒绝、撤回及重新提交，创始人本人操作免审 |
| 内容变更/删除 | 创建人改定义需上级审，创始人可改他人定义；责任人固定。删除暂按#22：创始人直删、创建人符合条件的未开始任务直删，已开始申请审核。保留历史 |
| 审核详情 | 当前有效审核人可读相关单条任务，撤回/决定/组织变化后临时权限失效；不扩大普通列表、日志及私密备注权限 |
| 任务私密备注 | 已生效且正常可见的任务可写本人备注，最多2000字；保存和清空走后端，别人包括上级不能读你的备注。未保存输入按服务/用户/任务留在本机；失败保留 |
| 日志 | 上海今天及前三天可创建单日或连续多日记录；创建后24小时内可改/提交，不延长窗口，日期范围固定。草稿本人可见，已提交不能退回草稿，时间显示到秒 |
| 视图/标签 | 任务月周日历与日志分离，保留年月直选。创始人维护标签，业务成员选择；任务/日历颜色一致。关键词变更审核保留 |
| 公司/个人事项 | ADMIN Web维护公司事项，各人备注独立；个人十大增删改、拖拽、后端同步、离线草稿及版本冲突处理 |
| 通知/账号 | 通知及已读走真实接口，失败保留未读并可重试；授权消息定位申请，旧无引用消息进申请列表。需刷新获取通知，不是手机离线推送。头像和改密已接后端，改密使旧会话失效 |
| Web请求 | 公司事项列表/保存/启停绑定会话与请求版本，旧请求不覆盖新账号/表单；备注保存期保护输入 |
