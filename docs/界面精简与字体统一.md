# 界面精简与字体统一 0.9.5

页面标题下的说明段落统一移除，另清理任务列表、查看上级、通讯录、任务关键词和日历空状态中的重复教学文案。错误提示、审批状态、只读状态、数量及确认对话框仍保留。

通讯录入口和铺在水墨背景上的返回、刷新、组织切换按钮使用带边框的半透明纸色底；描边按钮统一提供背景遮罩，提高深色墨迹区域的对比度。底色随浅色/深色主题切换。

原console_display.ttf缺少“讯”“签”等字，造成同一标题里回退混用字体。标题改用项目内完整Noto Sans SC中文字库，字重600，与正文的同系列字库统一。不会只对“通讯录”做单字替换。

此版仅修改安卓界面，后端沿用0.9.3版本，无数据库迁移。

模拟器检查：工作视图通讯录入口、通讯录标题/返回/刷新按钮已截图核对。补充日历切换按钮纸色遮罩，日程截止时间仅显示HH:mm，避免窄列拆行。

按钮对齐：主按钮、描边按钮、文字操作按钮统一至少48dp高；返回/创建和返回/刷新行垂直居中；标签选择按钮与表单字段同宽，左右边界一致。
