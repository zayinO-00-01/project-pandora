登录背景仍自动播放；视频出现约 1 秒后开始淡入表单，淡入时长仍为 1.6 秒。删除标题宣传、登录解说、管理员说明与开发预览说明，只保留账号、密码、连接设置、登录控件和必要错误。连接设置初始收起，即使地址为空也须手动打开。刷新和写日志使用相同 36dp 可见高度、88dp 最小宽度和 48dp 触摸容器。

## 日期规则

以 Asia/Shanghai 的当天为准，允许新建、修改、提交七天前至今天的日志，两端包含。例如 2026-10-12 的可写范围是 2026-10-05 至 2026-10-12，共八个日期。其他日期的既有日志可完整查看，但不能改日期、正文或提交状态。无历史读取期限，原组织权限和草稿隐私仍成立。

后端 PUT 同时检查数据库中的原日期和请求新日期；旧日志不能通过改成今天绕过限制。原日期超期的修改/提交返回 403，新建或新日期窗外返回 400，原记录不变。GET 查询不受日期窗口影响。新的显式 Shanghai 日期验证取代 JVM 默认时区的未来日期判断。

Android 打开旧记录显示只读内容和返回按钮，没有保存/提交按钮；筛选历史日期的日历不设七天限制，只有编辑日期控件设最早可写日。保存、提交和恢复缓存均再次检查日期。Web 个人日志编辑页也按同一规则只读展示历史，后端仍为最终依据。

OpenSpec：`login-polish-log-window`。需要升级配套 API 才能从服务端落实限制；旧服务器不能仅靠 APK 阻止其他客户端绕过。
