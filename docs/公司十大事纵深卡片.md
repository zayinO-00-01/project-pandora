## 布局和操作

总览仅显示按现有顺序排列的前两项，一行两张卡片，不横向滑动展示其他项。“查看全部”进入完整两列卡片列表，可纵向滚动阅读所有已发布事项。只有一项时保留单张卡片；没有数据时显示原有空状态，不补造内容。

点击预览或完整列表中的卡片进入事项详情。公司内容仍由 Web 管理端维护，安卓只读；原有个人本机备注继续可用，直接打开预览也能恢复已有备注。个人十大事的拖动排序保持原样。

卡面使用纸白、青绿和铜色主题、细描边、错位底板和柔和阴影。轻微指针倾斜最大 4 度、按压抬升 2dp；触摸事件不消费页面滚动。系统关闭动画时采用静态卡面。浅深色模式共享语义配色。

## 技术选择

沿用用户此前选择的安卓原生方案，参考 [Depth Card 官方说明](https://pro.reactbits.dev/docs/components/depth-card) 的倾斜和层次原则，以 Compose 实现。没有安装 React Bits Pro 的 React 源组件，也未复制付费源码；本次无需 components.json、shadcn、授权密钥或新增依赖。[官方安装说明](https://pro.reactbits.dev/docs/installation) 面向 React 项目。

主要文件：`ui/CompanyDepthCard.kt`、`HomeScreen.kt`、`PriorityScreen.kt`，均位于 `android/app/src/main/java/com/projectpandora/app/` 下。
