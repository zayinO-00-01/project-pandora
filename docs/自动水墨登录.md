# 自动水墨登录

`0.4.27-ink-login` / versionCode 30，替代上一版滚动落地页。

打开未登录页面时先只显示画面，60 fps 视频自动、静音播放；首个视频画面出现约 2.5 秒后，既有登录表单用 1.6 秒逐渐显现，仍叠在播放中的视频上。无需滑动或点击进入。视频播完保留末帧。登录成功/进入开发预览后播放器销毁；切后台暂停，回前台继续。

减少动画设置下立即显示静态图与表单。视频报错时显示静态图并开放表单；解码器迟迟不就绪时最多等待 5 秒就开放登录。原登录处理、草稿和角色权限未变，工作区仍是静态图与手动浅色/深色。

背景视频没有重新生成，沿用上版已逐帧验证的 541 帧、60 fps 文件与一致接缝。当前浏览器预览为 `docs/landing-preview/ink60/autoplay.html`，以实际播放时间检查初始、渐显、完成和末帧；旧 `index.html` 留作上一版验证资料。

输入框与辅助文字使用薄纸衬底，保证在动态山水墨色之上可读。首幕不显示这些控件，衬底随表单一起显现；绘画与视频资源本身未改变。

浏览器验收确认初始视频自动播放且表单透明度为 0；约 2.7 秒开始淡入，约 4.2 秒完全显示；约 9.02 秒结束并保持末帧。表单输入、减少动画和视频失败回退通过，320/390/768 宽度无横向溢出。报告：`docs/landing-preview/ink60/autoplay-browser-validation.json`。

Android 模拟器确认首屏纯背景、无滑动/点击自动显现原表单、开发入口正常、切后台返回仍可登录。截图记录不包含 Android 系统启动图和安装更新画面。报告：`docs/landing-preview/ink60/autoplay-native-validation.json`。最终构建与 11 项 Android 单元测试通过。
