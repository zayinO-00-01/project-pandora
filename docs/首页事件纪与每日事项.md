# 首页调整（0.10.0）

底部“总览/导图”统一为“首页”，“视图”改为“公司”。首页移除个人十大事与个人日志两个窗口；日志独立页面继续可用。公司重要事项入口显示为“事件纪”。任务看板读取当前账号作为执行人的全部已生效且未删除任务，按优先级和截止时间排序；不使用原首页摘要的十条上限。查看全部仍展示相同执行人范围。

首页下方“每日事项”使用独立月历。点击日期查看当日个人 todo，可新增、编辑、完成/取消完成、删除和刷新；与任务、日报没有关联，不触发派发或审核。正式账号保存在服务器，按账号隔离，创始人也不能读取他人的个人事项。开发预览仅使用隔离的本地示例存储。

接口（登录业务账号）：
- GET /api/v1/personal-todos：读取本人全部事项。
- POST /api/v1/personal-todos：新增；body 为 {title,date,completed}，返回含服务器生成 id 的记录。
- PUT /api/v1/personal-todos/{id}：修改本人记录。
- DELETE /api/v1/personal-todos/{id}：删除本人记录。
- date 格式 yyyy-MM-dd；title 必填、最多200字。不存在或不属于本人返回404。

部署新版后端时 Flyway 自动运行 V21__personal_todos.sql 创建独立 personal_todos 表。必须同时更新 APK 和后端 JAR；旧服务会显示每日事项读取失败，不会将其混存到公司任务或日报。
