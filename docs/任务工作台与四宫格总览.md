# 0.6.0 任务工作台与四宫格总览

开发与交付目录：`C:/Users/adwe2/Desktop/project-pandora`。

## 总览

采用最新参考图的四宫格顺序：左上公司十大事、右上公司派发任务、左下个人十大事、右下个人日志。保留现有工业控制面板配色、纹理、黑色边界和轻量按压反馈。公司卡片使用紧凑深度样式，查看全部后展示完整卡片。个人事项仍支持长按拖动排序。

## 任务与日志分离

“视图”中的月、周、日只映射任务截止时间，不再显示日志。任务列表含本人创建、本人负责和已有授权范围内的全部任务，含已完成；无截止时间的任务也在完整列表中。选择公司任意有效业务成员作为责任人不会扩大日志查看权限，ADMIN及停用账号不可被选为责任人。

## 审核、编辑与删除

- 创始人创建、编辑、更新进度与删除直接生效（用户最终确认）。只有创始人有删除权限。
- 其他业务成员创建任务、再次编辑任务及提交进度，由申请人的当前直属上级审核。无有效上级时明确提示，不绕过审批。
- 任务内容由创建人或创始人编辑；进度仅责任人反馈。
- 任务创建待审时，申请人与审核人可见；批准后进入责任人的工作列表。待审编辑和进度不覆盖原生效内容。拒绝后保留原内容；申请人可撤回申请后重新提交。
- 同一任务同时只允许一条待审变更。重复审批、非指定审核人和自审被拒绝，审批时复核组织关系和任务版本。
- 创始人删除后任务从列表和日历移除，待审变更取消；审核历史与通知保留。
- 在“职能”或“我的”进入“通知与审核”，可查看待办、变更说明和结果。通知是持久化的应用内消息，通过刷新读取，未接入系统离线推送。

## 品牌标签

创始人在“我的 → 维护品牌标签”维护名称、预设色或自定义 `#RRGGBB` 颜色。所有业务成员可在任务和日志编辑器选择已有标签。任务卡片和日历短标题使用相同颜色；更新标签后同步反映。停用标签不破坏历史关联，但不再提供给新事项选择。

## 日志编辑时限

保留今天及往前3天的创建范围，可创建一份连续多日的工作记录或草稿。日志日期范围创建后固定，正文与标签可在 `createdAt ≤ 当前时间 < createdAt + 24小时` 内修改/提交；跨午夜仍可修改，更新不会重置时限。历史日志不进入任务视图。

## 账号

“我的”支持从系统图片选择器更换头像、移除头像，以及输入当前密码修改密码。头像在设备上裁剪为正方形并压缩；后端验证真实PNG/JPEG内容、尺寸及体积。密码修改后所有旧会话失效，需用新密码重新登录。

## 升级与验证

必须同时更新APK及后端；旧后端没有标签、任务审核、通知、头像及密码修改接口。数据库新增V8个人资料迁移、V9审核/标签/通知迁移、V10显式外键迁移；保留V7多日日志迁移。测试与打包使用独立后端输出目录，避免覆盖本机正在运行的旧JAR。

自动化检查覆盖任务授权、审核前后内容不变/生效、拒绝、自审和重复审批、全公司责任人、标签权限、通知归属、头像验证、密码撤销会话、24小时修改边界及日志日期范围。原生日历不包含日志，首页四宫格需在模拟器检查窄屏与字体放大后的布局。
