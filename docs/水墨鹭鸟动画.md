# 水墨鹭鸟动画

版本 0.4.30-ink-herons / versionCode 33，2026-10-13。

## 已实现

原来的两条线飞鸟已移除，视频从四张干净的水墨画重新合成。实际使用生成素材中的鸟身、近侧羽翼、远侧羽翼；不是仅将素材放入参考文档。鹭鸟保留收拢颈部、尖喙、尾部和后伸长腿，羽翼有覆羽与飞羽层次。肩背连接位置经过解码画面检查后调整。

肩、肘、腕驱动羽翼纹理的三维投影。下压阶段较快且展开，上抬阶段略收翼并后掠；翼尖有轻微滞后和弹性变化。中途平滑切入短暂滑翔，鸟身仅小幅起伏和倾斜。三只鸟使用不同远近、透明度和拍翅相位，连续穿过上方留白，不在每个山水过渡处重新出现。鸟的活动区域避开居中的标题与表单。

形态参考：[Cornell Lab 鹭鸟飞行识别](https://www.allaboutbirds.org/guide/great_blue_heron/id)。动画频率约 1.55Hz 是画面设计参数，下压占周期 44%、上抬 56%；并非该物种的实测频率。

## 生成与复现

素材：`docs/landing-preview/ink60/heron-texture-atlas.png`（1536×1024，RGBA），由内置 image_gen 生成。提示要求：透明四分区贴图；左上为向左飞行、颈部呈收拢 S 形、长腿后伸的灰鹭鸟身；右上为展开的近侧翼上表面；左下为远侧翼下表面；右下为独立飞羽；使用细腻的中国水墨羽毛笔触、灰青墨色、自然解剖结构，不含背景、标签或简笔海鸥符号。原始贴图保持不变，渲染时裁切组件并映射到动画网格。

可复现代码：[render_ink_herons.py](../scripts/render_ink_herons.py)。需要 Python、Pillow、NumPy 和 FFmpeg；默认寻找项目本地 FFmpeg，也可传入 `--ffmpeg` 指定路径。

```powershell
python scripts/render_ink_herons.py --ffmpeg '你的ffmpeg.exe路径'
```

`--preview` 仅生成姿态图和场景预览。完整渲染输出 `docs/landing-preview/ink60/ink-herons-60.mp4`；安装包使用相同字节的 `android/app/src/main/res/raw/ink_journey_60.mp4`。所有骨架和纹理处理都在离线完成，手机仅解码视频。
