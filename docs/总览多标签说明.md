# 总览卡面与多标签

总览四类事项复用 CompanyDepthCard，统一描边、圆角、编号及按压效果。标签在左下角显示彩色短横线，每个标签一根，较多时换行。右下角菜单打开多选标签弹窗，保存后跨设备保留。

GET /api/v1/content-labels 返回有权查看的内容标签；PUT /api/v1/content-labels/{kind}/{id} 接收 {labelIds:[1,2]}，空数组清除。kind 为 company、task、personal、log，最多12个、不重复，禁用标签不可新增。公司事项仅创始人可设置，任务仅创建人/负责人/创始人可设置，个人事项及日志仅本人可设置。不修改公司事项正文。

新增 V20 表保存标签集合，无删除历史数据。未设置集合的任务/日志兼容显示原单标签。此次彩线作用于总览卡面，日历仍沿用原来每天单一底色的规则。

需要配套升级安卓 APK 与后端 JAR。

验证：后端133项测试通过，涵盖多标签保存/清空及越权拒绝。安卓沿用74项回归测试。此次未进行真机视觉验收。

## 0.9.2 全页面横线与表单多选

此次替代前述日历单底色规则：月/周日期格不再按标签填色，而汇总当天任务的不同标签，以多根彩线显示；选中日期仍保留普通选择态。日程任务卡、全部任务表格和任务详情恢复纸色底色，在内容下方显示彩线；日志列表同样使用彩线。

新建、编辑任务及日志均提供多选标签。请求新增 labelIds（最多12个）；创建时随主体事务保存，任务定义变更经审核后再应用标签集合，日志保存时同步应用。任务详情提供独立的标签多选保存入口，与既有总览标签入口共用后端数据。历史单标签仍作为未设置新集合时的兼容来源，空数组可明确清空。

无需新增数据库迁移，沿用0.9.1的V20标签集合表。需同步安装0.9.2安卓包和配套后端。
