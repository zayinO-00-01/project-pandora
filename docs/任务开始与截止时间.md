# 任务开始与截止时间（0.8.2）

基于队友最新版本 `21bbb37`（包含 main `c8838ff`）实现。

- 新建、编辑任务均提供「开始时间（选填）」和「截止时间（必选）」；按北京时间选择日期和时分。
- 开始时间可留空、可清除；截止时间为空时禁止提交。开始时间不得晚于截止时间，允许相同。
- 开始时间随草稿保留，编辑时回填，任务详情展示；普通成员修改后沿用当前直属上级审核流程，批准后生效。
- API POST /api/v1/tasks、PUT /api/v1/tasks/{id}：`startAt` 为可选 ISO8601 时间或 null；`dueAt` 为必填 ISO8601 时间。
- 任务列表响应增加 nullable `startAt`。日历继续按截止日期映射任务，排序规则不变。
- 数据库新增 V19 的 nullable `start_at`，不修改历史迁移和已有任务。历史无截止时间的任务可继续查看，编辑时需补全截止时间。
- 需一起更新 APK 和后端 JAR；旧客户端不传截止时间的请求将收到 400 提示。

交付文件位于桌面项目 deliverables，后端从 backend 目录启动以沿用原数据库；Flyway 自动执行新增迁移。
