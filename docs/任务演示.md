# 任务派发与进度演示

这是日志 MVP 后的任务增量，日志流程继续可用。领导安排工作，员工反馈进度，领导查看结果。

## 操作步骤

1. 启动 `start-demo.cmd`，电脑打开 http://localhost:8080，用 `leader / demo1234` 登录，进入“任务派发”。
2. 新建任务，例如“完成登录页联调”，责任人选择“员工小王”，填写详情、优先级和截止日期，派发。
3. 安装新版 `deliverables/Pandora-MVP-debug.apk`（可覆盖旧版），用 `staff / demo1234` 登录同一服务。打开任务并刷新；首页右上派发板块也应有这个任务。
4. 员工打开详情，反馈进度 50，说明“登录接口已接通，正在调整页面”，保存。Web 刷新后应显示“进行中”、50% 和同一说明。
5. 员工把进度改为 100，说明“登录页联调完成”，保存。Web 刷新应显示“已完成”；任务 ID 始终不变。
6. 重新启动服务，刚才的任务和进度应仍在。尝试保存失败时，输入应保留。

领导只能派给直属员工；管理员可派给其他非管理员成员；只有当前责任人能反馈进度。进度 0/1–99/100 分别对应待开始/进行中/已完成，允许责任人纠正进度。
