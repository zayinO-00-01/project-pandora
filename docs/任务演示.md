# 任务演示（本地整合版）

演示账号密码为 `demo1234`。Web用admin维护账号与直属上级，Android用业务账号操作。

1. staff新建任务，责任人选择自己。任务显示待审批，不能反馈进度，也不进入执行日历。
2. team_lead打开待办审核，批准这条自主任务；staff刷新后可以选择进行中并填写说明。
3. staff提交完成，team_lead验收通过；驳回时须填写原因，员工继续处理后可重新提交。
4. team_lead向staff派发另一条任务。派发后直接可执行；完成提交由team_lead验收。不能向无授权关系的人派发。
5. team_lead修改自己创建的任务，leader审核。批准前保留旧内容；审核页可对照修改内容。
6. 创建人和责任人分别添加关键词。staff修改team_lead的词条，需由当前直属上级审核；自己的词条可直接改。
7. 打开站内通知，检查未读数、跳转和标为已读。查看日历，直接选择年份和月份，再切换月周日。
8. founder自建任务直接生效。创始人创建的任务沿用直接完成；ADMIN只在Web维护资料与公司事项。

自建审批、完成/内容变更/删除审核、协作关键词审核是三类操作，Android收件箱统一展示，后端分别保存状态。具体日期规则、验证结果和手机验收见[MVP验收](MVP验收.md)。
