# 任务演示（老师方案整合版）

演示账号密码为 `demo1234`。Web用admin维护账号与直属上级，Android用业务账号操作。

1. staff新建任务，责任人选择自己。任务显示待审批，不能反馈进度，也不进入执行日历。
2. team_lead打开待办审核，批准这条自主任务；staff刷新后可以提交进行中说明，当前直属上级批准后进度才生效。
3. staff提交完成，team_lead审核通过；拒绝或撤回后保留原生效进度，员工可重新提交。
4. team_lead向staff派发另一条任务。创建后由leader（team_lead的直属上级）批准才可执行；staff提交进度交其直属上级team_lead审核。责任人可选全公司有效业务成员，不扩大日志权限。
5. team_lead修改自己创建的任务，leader审核。批准前保留旧内容；审核页可对照修改内容。
6. 创建人和责任人分别添加关键词。staff修改team_lead的词条，需由当前直属上级审核；自己的词条可直接改。
7. 打开站内通知，检查未读数、跳转和标为已读。查看日历，直接选择年份和月份，再切换月周日。
8. founder自建任务直接生效。创始人本人作为责任人反馈进度免审，创始人派发给员工不免除员工进度审核；ADMIN只在Web维护资料与公司事项。

创建初审、内容变更/删除审核、通用进度/关键词审核分开处理，Android收件箱统一展示，后端分别保存状态。具体日期规则、验证结果和手机验收见[MVP验收](MVP验收.md)。
