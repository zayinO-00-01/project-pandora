# Android任务闭环

1. 启动服务，Android用team_lead/demo1234登录。
2. 任务派发入口填标题、详情、优先级、可选截止时间，责任人选staff，提交。
3. 切换staff刷新任务，反馈进度50及说明；上级刷新看到最新内容。
4. staff改为100，上级刷新显示完成，同一任务ID；服务重启后记录仍保留。

FOUNDER/DEPT_HEAD/TEAM_LEAD仅能派给实际下级树中的较低角色，不能派自己、上级或无关成员。ADMIN和STAFF不能派发；只有责任人能反馈。向上查看批准不授予写入或派发权。创始人可读公司业务任务，部门/团队领导按下级范围，员工读本人负责的任务。

进度严格0–100整数，说明非空最多2000字；0/1–99/100对应待开始/进行中/完成。截止时间可不填，后端存ISO8601时间点，App按上海时区展示。保存失败保留输入。

后续优先项待小组安排：公司/个人十大事、备注资料、任务请示邀约、其他日历与主题。当前查看上级申请不是任务邀约。
