# Android 任务与日程演示

先启动本地服务，安装新 APK（0.5.1，版本号35），使用同一个服务地址。初始密码均为 `demo1234`。

1. `team_lead` 登录，从总览进入任务，派发给 `staff`；填写名称、优先级和说明，用选择器设置截止日期、时间。
2. `staff` 登录，打开任务，点击“反馈工作进度”，选择“进行中”，写实际进展后提交。
3. 上级刷新，看到“进行中”和说明，页面没有百分比和任务进度条。
4. 员工改为“已完成”并说明结果，上级刷新后看到完成；记录保持同一任务。
5. 打开“视图”，切换“周”，查看这一周的日志和到期任务；左右切换上一周/下一周。无截止时间的任务仍在任务列表。

需要手动确认的操作：选择日期后取消选时间，原截止时间应保留；“清除”后可不设截止；反馈未提交就返回/重新登录，输入应保留；断网提交应明确失败且保留输入；新建日志能直接打开编辑。

反馈只保留“待开始／进行中／已完成”和进度说明（必填，最多2000字）。旧任务和旧草稿也不再显示百分比，原状态和说明保留。

FOUNDER/DEPT_HEAD/TEAM_LEAD只向实际下级树中的较低角色派发；ADMIN、STAFF不能派发。只有责任人能反馈，查看上级的授权不包含修改或派发权。

本轮保留现有水墨外观。公司事项发布待与老师确认；个人重点编辑、备注和任务请示后续再做。查看上级申请与任务请示是两个功能。
