# 任务视图整合与标签显示（0.6.1）

- 底部导航为总览、日志、视图、我的，取消职能入口。
- 视图保留任务月/周/日历与所选日期详情，下方整合创建任务、待处理/本人派发摘要、全部任务、通知与审核、品牌标签、部门成员/查看上级入口。
- 全部任务包含当前本人及已有权限范围内任务，日志保持独立。
- 所有成员可从“我的”或视图下方查看品牌标签；维护仍仅限创始人。任务与日志编辑器可选择已有标签。
- 月历/周历以整个日期格显示标签底色，一天仅一个颜色；去掉摘要独立色块。多标签时沿用任务顺序：未完成优先，再按优先级、截止时间及任务ID选择首个带标签的任务。选中使用同色系文字下划线和日期加粗，保持单一底色。
- 标签单独加载并即时保留，不再因审核或通知接口失败而丢弃标签。失败可重试；旧后端缺少标签接口会明确提示升级。
- 开发直接进入提供三个带品牌标签的示例任务，用于查看标签列表、任务卡和日历的颜色。示例只存在本地开发预览，不写入业务数据库；创建与维护真实标签需登录创始人账号。
