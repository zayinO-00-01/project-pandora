# 协作关键词与总览转场（0.7.0）

## 使用

- 任务详情提供“任务关键词”，以简洁的圆角胶囊显示，可添加需求、联调、验收等短词。
- 任务创建人与当前执行人可共同新增关键词。自己添加的词可直接修改或删除；修改、删除他人添加的词由操作人的直属上级审核，创始人免审核。
- 审核前原词继续显示；原词、新词、申请人、审核人在“通知与审核”可见。拒绝保留原词；批准才替换或删除。申请可撤回。组织关系变化后仍需重新核对审核权限。
- 每任务最多12个关键词，每词1至24字，不能重复或包含控制字符。非参与人只读；待创建审核的任务先完成创建审批。任务已有待审变更时先处理审核。
- 保留原来的颜色标签，由创始人维护、全员选择；关键词用于说明任务，颜色标签继续决定任务卡和日历的底色，一天只有一个底色。
- 刷新、写日志从页头移到右侧固定悬浮层，纵向排列、半透明底色。滚动不改变位置，按钮以外仍可正常滑动内容。编辑和任务详情中隐藏悬浮操作以避免干扰表单。
- 总览四个查看全部入口使用原生 Compose 缩放、淡入展开，展开方向与卡片方位相应；遵循系统动画时长设置，系统关闭动画时直接显示。未增加第三方动画依赖。

## 安装升级

安装 [Android 0.7.0](../deliverables/Pandora-0.7.0-collaborative-tags-debug.apk)，versionCode 48，并同步使用 [配套后端](../deliverables/Pandora-0.7.0-collaborative-tags-api.jar)。不要只更新APK后继续连接旧后端，否则关键词接口不可用。

停止当前旧后端后，从项目 backend 目录运行，以继续沿用数据目录：

```powershell
Set-Location C:/Users/adwe2/Desktop/project-pandora/backend
java -jar ../deliverables/Pandora-0.7.0-collaborative-tags-api.jar
```

新增 V11 迁移创建任务关键词表；保留旧迁移和既有颜色标签。关键词接口为 `POST /tasks/{id}/keywords`、`PUT/DELETE /tasks/{id}/keywords/{keywordId}`，变更审核继续使用 `/task-reviews`。完整请求与权限见 backend/openapi.yaml。
