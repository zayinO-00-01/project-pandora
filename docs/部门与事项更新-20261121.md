# 部门与事项更新（0.10.9）

- 通讯录按最近的部门老总及其所有层级下属归属部门；创始人可查看全公司。未配置部门老总的账号只返回本人。归属由服务端限制，返回 departmentId、departmentName（负责人姓名的部门）。
- 联系人详情的工作信息仍由原有上下级权限校验，任务增加月历和当日列表。
- 前台每 3 秒读取通知，生命周期停止时停止轮询。已授予系统通知权限时，新收到的未读消息产生系统提醒，点击进入通知页。后台及退出后的持续推送未接入。
- 通知及审核申请人、审核人优先显示姓名；无姓名才回退账号。
- 任务详情返回公司；隐藏任务关键词编辑区域；现有任务标签用文字展示，点击进入本人相关任务的标签筛选。
- 已生效任务增删或替换标签提交修改者直属上级审核，创始人免审；获批前保留原标签。
- 每日事项支持可选 startAt、endAt，使用上海本地日期时间（不含时区偏移）。结束不能早于开始；跨日事项显示在涵盖日期，拖动保持时间跨度。兼容旧的 date-only 事项。
- 日视图按 00:00–23:00 时间轴显示选中当天任务，按开始时间分组，历史无开始时间时使用截止时间。

## 部署

Android 与配套后端一起更新。后端启动执行 V24__personal_todo_schedule.sql，给个人事项添加 start_at、end_at 两个可空字段。没有部署到线上，也没有修改真实账号或个人记录。
