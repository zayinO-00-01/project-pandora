# 二期 CRM 演示

在已有一期数据库上更新后端，Flyway 会运行 V30 和 V31，新增客户、业务、订单、台账和合同表，以及流水的登记编号。Web 更新后，系统管理员在「二期授权」给各演示人员分配权限；创始人自动可看营收汇总。Android 连接同一个后端，在「公司 → 客户与业务」进入。以下使用虚构数据即可，无需外部商城。

| 账号 | 演示需要的权限 |
|---|---|
| 运营员工 | 登录 App 办理客户和服务。需要导入或核对重复客户时，再分别授予对应模块。 |
| 财务 | 收退款与台账。可回看线上、线下流水。 |
| 行政 | 员工档案与合同。 |
| 模块纠错员 | 年卡核销撤销、服务更正按需授权；仍须有权查看对应记录。 |
| 系统管理员 | 管理账号和二期授权。 |

1. **企业参访。** 运营在 App 新建企业档案，填企业名称和对接人。登记一次参访、选参与人，转交给另一成员。用新负责人账号在消息中心点「查看详情」，直接打开这次参访，将它标记为完成，写跟进备注并关联一条自己有权访问的已有任务。若手机已允许系统通知，也可点通知栏提醒进入。回到客户档案检查服务历史。也可以用其他部门员工试建同名档案，只应看到查重提示；指定运营用 Web 核对后关联，再登记另一条业务。
2. **商城和年卡。** 在 Web「商城导入」先选运营员为样例负责人，下载样例 CSV 并上传、预览、确认导入。原文件再导入一次，应全部跳过。运营在 App 打开样例客户，登记并完成一条观演，然后从年卡点「登记到场」：剩余次数应从 6 变成 5。用有纠错权限的账号填写撤销原因，次数恢复为 6，历史仍在。再次尝试撤销同一笔应被拦住。
3. **参访款项。** 财务在 Web 找到参访，设置应收 3000 元。此时 App 状态应同时显示「已完成」「未支付」。用同一个月的实际日期登记 3000 元到账、500 元退款；查看「企业参访」该月分类的增量，净实收增加 2500 元。没有财务权限的运营 App 不显示金额。若登记时掉线，恢复网络后留在原标签页，点「重试确认」，核对台账仍只有一笔对应流水。
4. **员工合同。** 行政在 Web 选择员工，上传虚构 PDF，结束日期设成今天之后第 30 天。连续点两次「检查 30 天内到期合同」，同一授权行政账号只收到一条该合同的提醒。用普通业务账号检查，不能查看原件。

模拟 CSV 的商品代码是 `MEMBERSHIP`、`ANNUAL_CARD`、`GENERAL`；支付状态是 `UNPAID`、`PAID`、`PARTIAL_REFUND`、`REFUNDED`。金额填元，日期填 `YYYY-MM-DD`。补录退款时保留原订单号、原支付日期、原金额和负责人，填写累计退款金额及本次退款日期。例如一张 600 元的年卡先退 100 元，再退 500 元，第二次填累计退款 `600`，状态填 `REFUNDED`。按笔补录才能保留每笔退款的月份。

合同最大 1 MB；默认每天北京时间 08:00 检查到期。服务、收退款和核销均使用北京时间。先用样例数据完成演示，再根据实际反馈调整页面和流程。
