## 4. 手工/未自动化项

- Web 界面的浏览器点击流程（切到「公司十大事项」页、选事项、写备注、保存）**未自动化**，本轮以 `npm run build` + 同接口的真实 HTTP 端到端作为替代证据，仍需人工在浏览器复核一次。
- Android 备注改造已编译通过并出包，但未在真机/模拟器上点按验证（本机无 adb 设备）。
- **V6→V8 增量升级未在副本库验证成功**：本机 H2 把既有 `.mv.db` 判定为只读（该文件带沙箱的 Low 完整性标签与 `NW` 策略），Flyway 写 `flyway_schema_history` 时报 `90097 The database is read only`。同一份代码在全新库上从空库跑到 v8 正常，因此判为环境问题；请在非沙箱机器上补一次「V6 旧库 → 启动新版本 → 老账号仍可登录」的验证。迁移本身是纯增量（8 个可空列 + 2 张新表 + 唯一索引），不涉及删列或改类型。

## 5. 数据与安全说明

- 身份证号明文存储，仅用于课程演示；生产需加密或脱敏，已写入 `openspec/changes/web-profile-company-top10/design.md` 的风险项。
- 备注表 `company_notice_notes` 以 `(notice_id, user_id)` 唯一约束，保障「每人每条一条备注」。
- 启用上限 10 条在服务端强制，并发发布超限返回 400。
