# 水墨落地页 · 60 fps

版本 `0.4.26-ink-entrance` / versionCode 29。

视频仅用于登录前独立落地页，内容为纸墨、飞鸟、山水和留白，不介绍日志、月历或工作区。画面固定浅纸色，不随工作区主题改变。顶部可直接登录，末幕可进入登录，播放器在离开落地页时释放。工作区继续使用静态背景与手动浅色/深色。

## 制作方式

使用 imagegen 内置工具生成初始纸墨画面和后续山水状态。第一段实际末帧 `ink-1-last-seed.png` 作为下一状态的图像生成输入；第二段末帧作为第三段轻微运镜的起点。初帧提示见 `纸墨背景与月历排版.md`。后续提示强调保留纸色、左下/右上墨色和原有景物位置，只逐步显出山与水，排除文字、工作对象、边框和长铜线。

未调用未连接的 AI 视频模型。视频由生成绘画、程序绘制的墨色飞鸟振翅、叠化与细微运镜合成，不能称为 AI 直接生成的物体运动。成片 H.264、540×960、60 fps、541 帧，约 9.02 秒；使用每帧关键帧以便双向滚动定位。

运行资源：`android/app/src/main/res/raw/ink_journey_60.mp4`。
浏览器验证页：`docs/landing-preview/ink60/index.html`（需本地 HTTP 服务，支持视频 Range 请求）。

合成源码：`scripts/Render-Ink-Film.py`。需要 Python、Pillow、numpy 和 FFmpeg（加入 PATH 或通过 `FFMPEG_PATH` 指定）。依次运行 `python scripts/Render-Ink-Film.py first` 与 `python scripts/Render-Ink-Film.py finish`，输入为保留的生成画面。无需上传账号或调用付费视频模型即可重现合成流程。

## 接缝

`ink-transition-1.mp4`、`ink-transition-2.mp4`、`ink-transition-3.mp4` 分别包含 181 帧，边界有一帧重叠。主视频去除重复边界帧。分段取自主视频，解码后两处前段末帧与后段首帧像素完全相同，报告见 `docs/landing-preview/ink60/video-validation.json`。

60 fps 是视频编码帧率；具体设备的滚动显示与解码流畅度受设备性能影响。浏览器逐帧验证检查实际解码时间戳、非黑帧、不同画面数量、接缝与正反向滚动；原生验证另记录登录、月历和双主题入口。视频失败及减少动画模式均保留静态图和登录按钮。
