## Sprint 焦点

### Sprint 0（当前）

- 全员：需求故事、OpenSpec 初始化、低保真、接口/库表草稿
- P1：文档与看板；P2：架构；P3/P4/P5：各端页面草图

### Sprint 1（首条可演示链路）

`登录 → 写日志 → 个人面板可见 → 管理端/上级可见`

- P1 登录壳与角色；P2 用户+日志 API；P3 Android 写日志+面板；P5 Web 看日志；P4 日视图雏形或主题骨架

### Sprint 2

任务派发闭环、四大面板补全、月/周视图、管理端穿透；补单测与缺陷

### Sprint 3

停大新功能 → 修缺陷、系统/集成测试、两项非功能证据、测试报告与结题材料

## 两项非功能需求（建议）

1. **月相主题**：根据当天月相自动切换界面主题  
2. **安全/鉴权**（或性能，二选一敲定）：未登录不可访问业务接口；角色越权返回 403（易举证）
