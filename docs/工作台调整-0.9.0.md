# 工作台调整 0.9.0

1. 仅总览和日志页保留固定的刷新、写日志按钮；任务视图及其子页不显示。日志接口本身仍用于日志页。
2. 员工消息中心仅显示通知，隐藏审批和查看申请列表；后端拒绝员工访问管理人员的待审批列表。员工仍可在自己的任务详情中查看审核状态和撤回自己的申请。
3. 任务开始时间选填、截止时间必填，均用日历选择日期、上下滑动时分滚轮。开始不得晚于截止，编辑回填和审核规则沿用。
4. 全部任务仅显示本人创建或负责、且原本获准访问的任务，含已完成；排除仅因下属管理权限可见的其他任务。表格可横向滑动查看截止时间、优先级、状态、进度说明与负责人；点击行进入详情。原组织工作查看权限保持。
5. 视图页标题右侧为通讯录。组织内联系人按直属上级分组，支持姓名/账号/电话搜索、联系人详情及本机星标。GET /api/v1/directory 仅向业务账号提供有效业务成员的联系资料；不返回身份证、住址、生日等私人档案，不扩大工作信息权限。不含参考图中的外部联系人或聊天服务。
6. 新建日志仅今天、昨天、前天，每人每天一篇，草稿占用名额；重复请求返回409，后端以用户行锁串行化同用户创建以处理并发。日期选择不再支持连续区间。已有历史多日日志与重复记录均保留，不迁移删除；旧多日记录覆盖日期也阻止再新建日报。原24小时编辑规则保留，日期不可修改。

交付：deliverables/Pandora-0.9.0-workspace-revision-debug.apk 与 Pandora-0.9.0-workspace-revision-api.jar。需同时升级两端；从 backend 目录启动后端以使用原数据库。此次无新数据库迁移。

## 验证

- 安卓 74 项单元测试、后端 132 项测试通过，APK 与后端 JAR 构建成功。
- 独立内存数据库 HTTP 验收：6 个并发创建同用户同日期日志请求，1 次 201、5 次 409；三天前及多日创建均返回 400。
- 员工访问管理审批列表返回 403；匿名、管理员不可访问业务通讯录，通讯录不含私人档案字段。
- 原生模拟器验收：视图入口及悬浮按钮范围、员工消息页、通讯录搜索/详情/星标、任务滚轮滑动并保存、本人相关表格、三日日志入口与单日编辑。
- OpenAPI YAML 严格解析通过。未在实体手机或独立 MySQL 实例运行本轮验收。
