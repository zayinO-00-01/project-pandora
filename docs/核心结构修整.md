# 评分循环前的核心结构修整

当前结构版本：`0.4.15-light-dark` / versionCode `18`。最近一次独立盲评分数为第 23 轮的 `7.4/10`；本次结构修改不预设分数，先验证后恢复盲评。

最近多轮意见反复集中在构成、状态语法和时间结构。部分意见对按钮强弱、位置的建议相互不同，本次按页面职责建立稳定规则。

| 核心问题 | 本次规则 | 实际验收 |
| --- | --- | --- |
| 月历选中一天，下方却展示整月记录 | 月历用于定位；选日保留网格，下方只显示该日记录 | 本地服务加载三天记录，选 10 月 9 日，确认仅出现该日条目；今天与内容点独立于选中下划线 |
| 三页空状态形成同一种标题与按钮模板 | 总览分别报告任务状态、引导今日日志；日志页引导首次记录；视图引导选择日期 | 浅色／深色三个空状态分别截图，检查没有重复创建入口 |
| 创建的颜色、形态漂移 | 写日志统一铜色加号文字，保留 48dp 触摸区；浏览、选择、进度更新用青色 | 创建打开实际编辑页并取消，不提交验收记录 |
| 同步失败替换任务栏目 | 独立显示失败、上次内容说明、原因与重试，保留任务栏目 | 实际 HTTP 503 下检查“接下来处理”“全部任务”仍存在，详情包含完整失败原因 |
| 公司、个人归属与三个分类入口关系不清 | 归属作为组标题，完整入口使用同宽行；数量带单位，箭头固定在同一列 | 320dp 大字号下检查归属和数量，实际打开公司／个人分类 |
| 各类文字依赖相似粗体与淡灰 | 焦点任务最强，阅读标题常规字重；任务状态青色，草稿隐私铜色；删除常态已提交的机械重复 | 对照总览、日志、议程的双主题截图；确认草稿仍可在编辑页提交 |

浅色／深色仍由用户手动选择，默认浅色并持久保存。月相自动模式已移除。没有添加虚构记录、统计或装饰来填满稀疏页面；验收记录来自隔离的本地 HTTP 服务。

最终安装包验收已完成：11 项业务测试通过；二十二张双主题正常／空／失败／多日期截图重新采集；320dp + 1.3 倍字号、375／414／768dp、失败详情、公司与个人索引跳转验证通过；写日志与更新进展可点击高度至少 48dp，编辑器取消且未提交记录。
