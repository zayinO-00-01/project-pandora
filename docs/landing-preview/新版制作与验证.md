# 山水、记录、时间线

初始图与后续状态使用内置 ImageGen 生成。影片使用真实生成图片进行镜头推进与短叠化，未使用 AI 物体变形视频模型。可用的视频模型服务要求连接账号，因此没有运行或收费。

第一段从初始山水画靠近笔记本；提取实际片段末帧作为第二幅图的参考。第二段进入日志纸页；提取它的实际末帧作为展开纸册的参考。最终单一影片包含 271 帧、30 fps，滚动位置映射到 0–9 秒；三个片段共享两处边界帧，正反滚动使用同一时间轴。

## 可读信息与来源

图片不生成文字。标题、日志、月历和任务由浏览器 DOM／原生 Compose 渲染；日志与任务明确标注“示例”，内容来自本项目本地 UI 验收夹具，不代表登录账号数据或产品宣传指标。

标题使用 Google Fonts 的 [Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc)，仅保留落地页标题字符，固定字重 500；许可保存在 Android assets 的 NotoSerifSC-OFL.txt。工作区的浅深主题不影响落地页。
