# Project Pandora 本周周报提纲

- 周期：2026-10-16—2026-10-22。
- 对照基线：上次《小组周报-2026-10-15》，Android 0.5.1-state-feedback（35）。
- 当前整合版本：Android 0.6.0-synced-workspace（45），配套 Web 管理端和后端。
- 统计口径：小组整体成果，包含 Android 前端、Web 前端、后端、整合联调、测试、数据库升级和文档。各模块先后由不同成员完成，本提纲不将所有成果归于某一人；姓名、工时和外部看板由组员按实际补充。

## 一、本周工作概述

在上周日志、任务和五角色权限原型的基础上，完成公司十大事项、个人十大事项和员工资料的业务补充，调整 Android 总览与职能页面，改进日历、任务展示和交互体验，并将原先仅保存在 Android 本机的事项和备注接入后端。

本周形成两个主要新增演示流程：

1. 管理员在 Web 发布公司事项 → 员工在 Android 阅读完整内容 → 保存仅本人可见的备注。
2. 员工整理个人十大事项 → 新增、编辑、删除和拖动排序 → 同步到服务器 → 重新登录或换设备读取。

保留原有日志记录、任务派发与状态反馈、组织范围查看及直属上级查看申请流程。当前目标仍为可本地运行、可现场操作的演示原型。

## 二、Android 前端工作

### 1. 调整页面结构与角色入口

- 底部导航统一为“总览、职能、日志、视图、我的”。
- 总览突出公司十大事项、公司派发和个人十大事项，减少页面中混杂的业务操作入口。
- 领导的职能页以派发任务和已派发任务为主；员工以本人待办为主，分别提供对应的组织与直属上级查看入口。
- 任务、成员及组织页面整理返回路径，保留已有派发和反馈草稿。
- 成员页支持姓名、账号搜索，提供匹配数量、清空和无结果提示，仅筛选已有授权范围内的成员。

### 2. 完成公司事项展示与交互

- 新增公司事项卡片：总览预览前两项，完整列表两列排列，可滚动查看。
- 调整卡片层次、边界、按压反馈及浅深色适配，保留完整详情入口。
- 正式读取 Web 发布的完整正文，修复原面板只返回标题、详情缺少正文的问题。
- 接入个人备注的真实保存和清空；未保存或保存失败时保留输入，区分待保存和已同步。
- Debug 保留明确标注的本地公司示例和开发预览，用于无服务时检查界面；不冒充真实发布内容，不向业务接口写入示例。

### 3. 完成个人十大事项与后端同步

- 支持新增、完整详情、编辑、删除确认，最多十条；标题最多120字、安排最多2000字。
- 支持长按拖动、卡片浮起和边缘自动滚动，取消拖动恢复原顺序。
- 将此前的本机清单接入后端，保存后可在新登录会话或其他设备读取。
- 保留旧版清单和备注，通过明确确认导入，避免升级时直接覆盖。
- 待同步清单按账号和服务器隔离保存在本机，连接失败时可恢复后重试。
- 增加跨设备修改冲突提示，提供载入服务器清单或确认覆盖的选择。
- 编辑开始时保留原始版本，修复编辑期间刷新导致绕过冲突检查的问题。

### 4. 日志规则和时间显示

- 采用本周确认的新规则：上海日期今天及前三天可新建补录，只有今天的日志可修改或提交。
- 历史补录直接提交，完成后只读；历史日志继续可查，禁止通过修改日期绕过限制。
- 调整日期选择范围、历史记录提示及草稿恢复时的校验。
- 日志显示服务端实际录入时间和最近修改时间，精确到秒。
- 这是对上周“七天内可编辑”规则的更新；不另行虚构提交时间字段。

### 5. 日历和任务展示优化

- 完善既有月、周、日视图切换和按月／周／天导航，保持同一选中日期。
- 月历日期格增加任务标题、日志首行摘要，详细安排在选中日期下方查看。
- 缩小月历周行和多余留白，优化小屏阅读、两行摘要和跨月跨年日期展示。
- 统一高／普通／低任务优先级颜色，按未完成优先、优先级、截止时间等规则排序。
- 任务详情增加“待开始→进行中→已完成”的状态阶段曲线，使用实际返回状态与最新反馈；不恢复完成百分比，也不伪造历史进度。
- 未设截止时间的任务仍从任务列表查看，不强行安排到某一天。

### 6. 个人页与通用交互

- 个人页接入本人资料读取，展示联系方式、入职及紧急联系人等已维护字段；未填写字段正常处理。
- 统一页头安全区、标题和操作按钮的留白，完善浅色细边框及深色适配。
- 改进按钮声音、触感、开关和试听入口，遵循系统静音及触摸反馈设置。
- 保留既有水墨登录与主题风格；本周主要为工作页面与交互完善，不将已有水墨视频重复记作全新成果。

## 三、Web 管理端工作

### 1. 员工资料维护

- 在账号管理中补充手机号、身份证号、出生日期、性别、入职日期、紧急联系人、紧急联系电话、住址等资料字段。
- 配合后端实现新建账号手机号必填、格式和唯一性校验，以及身份证号等资料检查。
- 继续使用已有角色、直属上级、密码和停启配置功能。
- 修复旧演示账号资料为空时的表单异常，包括空姓名、手机号及其他可空字段。
- 旧账号未填手机号时，可保留原状修改其他信息；填写手机号后仍执行有效性校验。

### 2. 公司十大事项发布

- 新增公司事项管理页，支持发布和修改标题、正文、顺序及启用状态。
- 支持停用和重新启用，最多十条启用内容，列表显示当前状态与数量。
- 已确认由 ADMIN 在 Web 发布，Android 业务角色只读原文并维护个人备注。
- 更新管理端入口及说明，明确 Web 负责账号、档案和公司事项，日常业务使用 Android。

## 四、后端与数据库工作

### 1. 员工档案及权限

- 新增档案字段和数据库迁移，支持管理员维护及本人资料读取接口。
- 增加手机号、身份证号等格式、唯一性及日期检查；普通成员列表不直接返回完整个人档案。
- 保留并检查五角色鉴权、实际组织范围、账号停用、他人草稿隐私及原有组织配置持久化规则。

### 2. 公司事项与个人备注

- 新增公司事项和个人备注的数据表、管理接口和业务读取接口。
- 支持管理员发布、修改、排序、停启与启用数量限制。
- 备注按事项和用户分别保存，只返回当前用户自己的内容，允许空字符串清空。
- 首页面板返回实际公司事项和完整详情，接通 Web 发布到 Android 阅读的链路。

### 3. 个人事项持久化

- 新增个人清单、条目存储和 V9 迁移，提供读取及整体保存接口。
- 支持新增、修改、删除和按列表顺序保存，服务端分配稳定ID。
- 所有权来自登录身份，校验数量、内容及条目归属，拒绝引用他人条目。
- 通过 revision 检测过期修改，并处理并发首次保存，避免两台设备静默覆盖。
- 聚合面板返回实际个人事项，不再固定为空列表。

### 4. 日志与旧库升级兼容

- 后端落实三天补录、仅当天修改和提交的规则，拒绝越界日期及改日期绕过。
- 处理 main 与旧 zayin 数据库迁移编号顺序不同的问题，不通过删库解决。
- 升级前备份，在副本预演并核对历史及全部原始业务字段；未知历史拒绝自动转换。
- 修复数据库目录内已有历史备份导致 H2 备份重名失败的问题。
- 实际演示库升级到V9后，原5个账号、10条日志、4个任务、0条申请的原始字段摘要一致，保留既有备份和本轮新增备份。
