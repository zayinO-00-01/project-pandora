# 日历连续拖拽与任务日期限制（0.9.8）

> 本页为 0.9.8 历史记录。其任务日期限制已被后续已确认规则取代：开始时间选填，可早于今天；截止时间必填，日期不得早于上海今天，开始不得晚于截止。Android 遗留限制已在本地 0.9.11 修正，见[项目检查-2026-11-06](项目检查-2026-11-06.md)。

- 参考视频已用本地 FFmpeg 解码并查看连续帧。日历高度随手指连续变化，松手以临界阻尼弹簧吸附；支持拖动中接管尚未结束的动画，保留周历、正常月历、展开月历三档及选中日期。
- 收起时将选中日期所在行逐渐移动到顶部；三种视图下方仍仅展示选中当天的任务。周历统一采用日到六的列顺序，与月历切换时日期位置保持一致。
- 移除工作日志列表顶部的今天、昨天、前天快捷按钮，保留既有悬浮写日志入口及编辑页日期选择。
- 新任务可选择前天、昨天、今天及未来日期；可选开始日期与必选截止日期均不得早于北京时间前天零点。Android 日期选择器、提交校验和服务器单个/批量创建入口均限制；既有任务编辑不套用新建日期限制。
- 不修改演示账号的日志数据。

验证：Android 单元测试、后端回归测试；原生模拟器录制慢速拖动，检查连续中间高度及日志快捷按钮移除。模拟器效果不等同于实体手机帧率测试。

交付：`deliverables/Pandora-0.9.8-fluid-calendar-debug.apk` 与 `deliverables/Pandora-0.9.8-task-dates-api.jar`。服务端必须部署新版 JAR 才能限制其他客户端直接调用旧日期创建接口。
