# 责任人多选与标签选择 0.9.3

标签选择按钮下方不再显示色线；勾选弹窗在每个标签名称前展示对应颜色的竖条。内容卡片仍保留紧凑色线，横竖可按排版调整。

创建任务支持选择1至100位有效业务责任人，搜索姓名/账号后可继续勾选，已选人员存入本机草稿。每个人得到一份独立任务，标题、说明、时间、优先级与标签相同，任务编号、进度、审核各自独立。编辑已创建任务仍保留原责任人，不变更为批量编辑。

POST /api/v1/tasks/batch 接收 {tasks:[TaskInput,...]}，返回201和任务数组；单人旧接口仍保留。空集合、超过100份、重复责任人和无效字段拒绝提交。整批创建为单个事务，任一项无效则整批回滚，包含任务、通知、事件和标签。

交付文件：deliverables/Pandora-0.9.3-batch-assignees-debug.apk、Pandora-0.9.3-batch-assignees-api.jar。需同时更新两端，无新数据库迁移。本轮未做真机视觉验收。

验证：安卓76项、后端137项测试通过，包含批量请求传输、独立任务编号和审批、重复人员与空集合拒绝及整批事务回滚。
