# 月、周、日视图（0.5.7）

2026-10-17；versionCode 41。

- 刷新按钮及日历“上一期 / 今天 / 下一期”三个按钮取消黑色边框；白色内容卡片保留黑色描边。
- 日历顶部提供“月视图 / 周视图 / 日视图”切换，沿用同一选定日期。切换视图会回到列表顶部。
- 月视图保持周日开头的整月日期、最多两排摘要及选中日安排。
- 周视图按照既有 `periodDates` 规则从周一到周日，包含跨月跨年的日期。日期条显示摘要，下方按日期展示整周日志和到期任务，空日期使用紧凑提示；“查看当日”进入对应日视图。
- 日视图只展示选定日期的完整日志与到期任务，可点击打开原有详情。
- 左右箭头分别按月、周、天切换；“今天”只重置日期，保留当前视图。优先级颜色与任务排序继续沿用。
- 仅显示当前账号已加载数据，没有截止日期的任务仍从职能任务列表查看。不新增接口，也不把未加载内容当作服务器已完整返回。
