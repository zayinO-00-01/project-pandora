## 统一设计语言

颜色单一来源为 `android/app/src/main/java/com/projectpandora/app/ui/ControlTheme.kt`：深海蓝 `#142F3B`、矿物白 `#F0F3F1`、铜橙 `#AA4929`、状态青绿 `#17655F`。铜橙用于主要动作；青绿用于进度与状态。背景采用带色相的实色，不依赖灰色渐变。身份面板只有低对比静态网格，不遮挡正文。

正文沿用 Android 系统中文无衬线字体，保证缺字率、字号缩放与平台可读性；日期、编号、进度采用系统等宽字体。标题 24sp，正文 14–16sp，辅助文字 12sp；组件小圆角 8–12dp、细边框、48dp 起的主要触摸目标。

主要按钮轻压缩至 98%，短行程下沉，阴影随按压收起。Compose 原生交互态支持禁用、加载、焦点、错误提示；动画遵循系统动画设置。震动通过系统触觉反馈；声音为本地生成的 75ms 轻音，不依赖网络。两项偏好在“我的”中单独设置并持久化，声音遵循系统静音与音量，不循环、不自动播放。

用户可在“我的 → 外观”选择浅色或深色。默认浅色，选择保存在本机，重启和退出登录后继续生效，系统栏随外观更新。仅保留两种手动模式，不使用月相自动切换。两套主题共享同一组件结构。

## 页面与需求映射

| 页面 | 本次实现 | 边界 |
|---|---|---|
| 登录 | 身份面板、账号密码、显隐密码、可收起连接设置、加载与错误 | 无公开注册，ADMIN 提示使用 Web |
| 导图 | 公司十大事左上、公司派发右上、个人十大事左下、今日日志右下 | 所有数据来自已有 API，无虚构统计 |
| 公司事项 | 列表、只读详情、已有备注阅读 | 公司写入与个人备注写入接口尚未提供 |
| 个人十大事 | 个人事项列表与状态说明 | 编辑及排序尚未开放 |
| 日志列表 | 日期选择、全部日期、新建、状态、每日校验提示 | 列表保留真实草稿与提交记录 |
| 日志编辑 | 日期、正文、字数、存草稿、提交、取消确认、失败输入保留 | 沿用 zayin 已提交日志可编辑的行为 |
| 任务列表 | 工作台、优先级、状态、进度、责任人、截止日期 | 从公司派发进入 |
| 任务详情 | 任务原文、责任、期限、进度说明 | 仅当前责任人编辑反馈 |
| 进度反馈 | 0–100 进度、必填说明、保存与失败状态 | 保留原有持久化缓冲与校验 |
| 日视图 | 当日日志与截止任务 | 无截止日期任务留在任务列表 |
| 周视图 | 周一至周日、日期标记、每日日志及任务 | 只使用当前已同步数据 |
| 月视图 | 按真实月份天数布局、有内容日期标记 | 点击日期进入日视图，支持跨月与闰年 |
| AI 地图 | 在“我的 → 当前服务”中明确尚未开放 | 不生成分析或职业判断 |
| 我的 | 身份、权限说明、浅色／深色外观、反馈设置、服务地址、退出 | 显示名编辑与组织成员选择待接口联调 |
| 派发／邀约 | 需求页面的入口与未开放表单说明 | zayin 仍通过 Web 派发；main 尚未实现任务写接口 |

尚未开放能力的目标表单采用相同工作面组件：事项备注为只读原文＋备注输入；个人十大事为可排序工单列表；派发为名称、优先级、期限、责任人、详情与关联人；邀约为上级、事项、优先级、期望时间和说明；资料为只读账号／角色与显示名。没有接口时不模拟服务端提交成功。

## 分支兼容

main 角色为 ADMIN、FOUNDER、DEPT_HEAD、TEAM_LEAD、STAFF；Android 接受四级业务角色，额外接受 zayin 的 LEADER 并标注旧版服务。管理员在登录或恢复会话时被挡在业务空间外；真正的组织授权仍由后端执行。

本次不把 main 后端覆盖到 zayin，避免丢失队友已实现的任务链路。main 缺少任务接口时，日志与面板仍可独立读取，任务区域显示接口失败并可重试。前端新角色兼容不代表旧后端已经实现四级穿透权限。
