# 低保真原型

文字线框，方便 Sprint 0 对齐页面，不是视觉稿。风格要求：信息短、卡通轻松，详细配色等画高保真时再定。

导航（Android 底部）：导图 | 日志 | 视图 | AI地图 | 我的

## 导图

```
┌─────────────────────────┐
│ 潘多拉            [刷新] │
├────────────┬────────────┤
│ 公司10大事  │ 公司10派发  │  只读
│ 1 ……       │ 1 ……       │  点进详情
│ 2 ……       │ 2 ……       │  可写个人备注
│ …最多10条   │ …最多10条   │
├────────────┼────────────┤
│ 个人10大    │ 今天的日志  │  点进去可改
│ 1 ……       │ 09:00 ……   │
│ 2 ……       │ 14:00 ……   │
└────────────┴────────────┘
│ 导图 日志 视图 AI地图 我的 │
└─────────────────────────┘
```

公司大事详情：标题、说明、我的备注输入框。员工没有「编辑原文」。管理员才有。

## 日志

```
┌─────────────────────────┐
│ 日志            [新建]   │
├─────────────────────────┤
│ 3月18日                 │
│ · 完成接口对接           │
│ · 写周报                 │
│                         │
│ 空状态：今天还没有日志    │
└─────────────────────────┘
```

新建页：日期（默认今天）、正文。正文为空不能保存。保存成功后回到列表。

## 视图

三个切换：日 | 周 | 月。数据只来自日志和派给自己的任务。

- 日：当天日志在上，任务在下，带进度。
- 周：七列，有内容的日期标个数。
- 月：日历，有内容的日期打点，点进去进日视图。

## 我的

显示名、角色（只读）、退出。改显示名一个输入框。

## AI 地图

第一阶段只有一句：尚未开放。不要做关键词和 MBTI。

## Web 管理端

```
┌──────────┬──────────────────────────┐
│ 日志     │ 团队日志                  │
│ 公司事项 │ [按人筛选]                │
│ 任务     │ 张三  3月18日  ……         │
│          │ 员工账号看不到本页         │
└──────────┴──────────────────────────┘
```

公司事项页：列表最多 10 条。管理员有编辑；其他人只读。任务页 Sprint 2 再加「派发」和「邀约」两个筛选。
