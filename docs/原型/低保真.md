# 低保真原型

对应需求 v0.5 的文字线框。界面简洁、轻松，月相主题只换颜色，不改布局。

导航（Android 底部）：导图 | 日志 | 视图 | AI地图 | 我的

## 导图

```
┌─────────────────────────┐
│ 潘多拉            [刷新] │
├────────────┬────────────┤
│ 公司10大事  │ 公司10派发  │  只读
│ 1 ……       │ 1 ……       │  点进详情
│ 2 ……       │ 2 ……       │  可写个人备注
│ …最多10条   │ …最多10条   │
├────────────┼────────────┤
│ 个人10大    │ 今天的日志  │  点进去可改
│ 1 ……       │ 09:00 ……   │
│ 2 ……       │ 14:00 ……   │
└────────────┴────────────┘
│ 导图 日志 视图 AI地图 我的 │
└─────────────────────────┘
```

上方两块：查看原文和自己的备注，员工不能编辑原文。右上提供“查看全部任务”，责任人进入详情更新进度。

下方两块：个人十大事可改内容、顺序和来源；日志点击进入编辑，草稿标记“仅自己可见”。

## 日志

```
┌─────────────────────────┐
│ 日志            [新建]   │
│ [日期选择] [全部状态]    │  每次请求检查登录与权限
├─────────────────────────┤
│ 3月18日                 │
│ · 完成接口对接 [已提交]  │
│ · 写周报 [草稿]         │
│                         │
│ 空状态：这一天还没有日志  │
└─────────────────────────┘
```

编辑页：日期、正文、“保存草稿”“提交日志”；已提交记录显示“保存修改”。草稿仅本人可见，提交后管理端按权限查看，修改后刷新可见。

正文为空、过长或日期在未来时提示错误；保存失败保留输入。列表加载失败提供重试，不当作空列表。

## 任务与请示

任务列表显示名称、责任人、截止时间、状态和进度。详情将指令原文、个人备注、进度操作分开；领导可创建任务，责任人更新进度。

请示页填写标题和说明，发给直属上级；上级回复并接受或拒绝。当前草案支持接受后转任务，是否保留与老师讨论。

## 视图

三个切换：日 | 周 | 月。数据只来自本人日志和本人作为责任人或关联人的正式派发；日志按所属日期，任务按截止日期归属，同一任务不重复计数。本人草稿加状态标识，邀约不进入日历。

- 日：当天日志在上，任务在下，带进度。
- 周：周一至周日七列，有内容的日期标个数，支持跨月/跨年；点击进入日视图。
- 月：日历，有内容的日期打点，点进去进日视图。

## 我的

显示名、角色（只读）、退出。显示名修改是 P1 可选功能，拟在 Sprint 2 增加一个输入框。

## AI 地图

第一阶段只有一句：尚未开放。不要做关键词和 MBTI。

## Web 管理端

```
┌──────────┬──────────────────────────┐
│ 日志     │ 团队已提交日志             │
│ 公司事项 │ [按人筛选] [按日期筛选]     │
│ 任务     │ 张三  3月18日  …… [更新时间]│
│          │ 员工账号看不到本页         │
└──────────┴──────────────────────────┘
```

公司事项页：最多 10 条，管理员可新增、编辑、删除、排序。任务页区分“派发”和“请示”。成员设置页仅管理员可维护角色和直属上级。

管理员看公司范围，上级看下属已提交日志；员工不能进入管理页。按人员、日期筛选，显示最新正文与更新时间。未登录提示登录，越权提示无权访问。
