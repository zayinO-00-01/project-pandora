# 低保真原型

文字线框，方便 Sprint 0 对齐页面，不是视觉稿。2026-09-19 随产品需求 v0.4 修订，待组内评审。风格要求：信息短、卡通轻松，详细配色等画高保真时再定。月相主题只换颜色，不改布局。

导航（Android 底部）：导图 | 日志 | 视图 | AI地图 | 我的

公司大事详情：标题、说明、我的备注输入框。员工没有「编辑原文」。管理员才有。公司派发详情同样支持个人备注；只有责任人能更新进度，指令标题、详情、责任人和截止时间不能由接收员工改写。备注仅本人可见。

右上仅展示权限内派发，最多 10 条，提供「查看全部任务」。个人十大事从本人已提交日志按确定性规则补足空位，最多 10 条，点击可改内容、顺序和来源；刷新不覆盖已整理条目。右下只展示本人当天日志，草稿标记「仅自己可见」。具体排序和生成规则见产品文档 §4.2。

## 日志

```
┌─────────────────────────┐
│ 日志            [新建]   │
│ [日期选择] [全部状态]    │  每次请求检查登录与权限
├─────────────────────────┤
│ 3月18日                 │
│ · 完成接口对接 [已提交]  │
│ · 写周报 [草稿]         │
│                         │
│ 空状态：这一天还没有日志  │
└─────────────────────────┘
```

新建页：日期（默认今天，可补记历史日期）、正文（1–5000 字符）。提供「保存草稿」「提交日志」；草稿仅本人可见，提交后上级/管理员按权限查看。已提交日志可由作者再次编辑，按钮为「保存修改」，管理端刷新后显示最新正文和更新时间。保存失败保留输入，正文为空或日期在未来时阻止保存并说明原因。

每次进入加载日志时正常检查登录和请求结果，不设每日首次的专用完整性检查。加载失败显示「加载失败，请重试」和重试按钮，与无记录的空状态区分。

## 任务与邀约

任务列表从公司派发板块进入，显示任务名称、责任人、优先级、截止时间、状态及进度。任务详情将只读指令原文、个人备注、责任人进度操作分开呈现；进度区不能修改原文。

领导可从日志页的「派发任务」入口填写名称、优先级、截止时间、责任人及可选详情、关联人。员工从「向上邀约」入口填写标题和说明，页面展示直属上级；未配置上级时提示联系管理员。邀约列表显示待处理/已接受/已拒绝及回复。接收上级接受时补齐正式派发字段，生成关联任务；拒绝时填写回复。不出现多级审批或统计图。

## 视图

三个切换：日 | 周 | 月。数据只来自本人日志和本人作为责任人或关联人的正式派发；日志按所属日期，任务按截止日期归属，同一任务不重复计数。本人草稿加状态标识，邀约不进入日历。

- 日：当天日志在上，任务在下，带进度。
- 周：周一至周日七列，有内容的日期标个数，支持跨月/跨年；点击进入日视图。
- 月：日历，有内容的日期打点，点进去进日视图。

## 我的

显示名、角色（只读）、退出。显示名修改是 P1 可选功能，拟在 Sprint 2 增加一个输入框。

## Web 管理端

```
┌──────────┬──────────────────────────┐
│ 日志     │ 团队已提交日志             │
│ 公司事项 │ [按人筛选] [按日期筛选]     │
│ 任务     │ 张三  3月18日  …… [更新时间]│
│          │ 员工账号看不到本页         │
└──────────┴──────────────────────────┘
```

公司事项页：列表最多 10 条。管理员有新增、编辑、删除和排序；其他有权登录 Web 的管理者只读。第 11 条和空标题显示明确错误。任务页 Sprint 2 加「派发」和「邀约」两个筛选，接收上级可处理邀约。

管理员查看全公司已提交日志；上级只看组织树内下属的已提交日志，不返回他人草稿和个人备注。员工不能进入管理页。接口越权返回 403，不因修改 URL 或筛选参数扩大范围；未登录返回 401 并引导重新登录。成员设置页仅管理员可配置角色和直属上级，自指或组织循环要提示失败。
