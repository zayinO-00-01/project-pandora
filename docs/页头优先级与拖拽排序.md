# 页头、任务优先级与拖拽排序（0.5.5）

2026-10-17，版本 `0.5.5-priority-drag` / versionCode 39。继续既有 OpenSpec `workspace-planning-three-day-logs`，本次只修改安卓及接口约定，不改 Web 或后端业务。

## 页头

所有已登录页面统一使用设备 safeDrawing 顶部安全区，再增加 12dp 顶部留白、6dp 底部留白。标题与写日志/刷新按钮一同下移，TopAppBar 内部不再重复计算状态栏；保留各页面原有高度与字体放大适配。登录背景与固定开发入口不变。

## 任务优先级

高优先级使用红色，普通使用青绿，低优先级使用灰色；深色主题用相应浅色，保留中文优先级文字，不依赖颜色单独表达。

所有已加载任务按以下规则排列：未完成在前 → 高、普通、低 → 同级截止时间由近到远 → 无/无效截止时间在同级最后 → ID 固定平局顺序。截止时间按 Instant 解释，支持不同 UTC 偏移，避免字符串比较导致顺序错误。完成任务放后，不因高优先级挤占待办。

总览公司派发、职能任务、完整任务列表、成员任务与日历任务复用相同规则。只有面板标题、尚未取到任务元数据的项目保持原面板顺序并放在有排序信息的项目后，不伪造优先级；后续同步成功后更新排序。日历先展示该日日志，再按上述顺序展示任务。

## 个人十大事

长按事项或右侧拖动柄，上下拖动即可调整先后；拖动时卡片浮起，靠近上下边缘自动滚动。松手提交顺序与 `sortOrder`，按当前服务器/账号写入本机清单；手势取消恢复原顺序，不覆盖持久化快照。卡片内边距缩至 12dp，间距 8dp，摘要只展示一行；取消上移/下移文字按钮，仅通过长按拖动排序。公司十大事没有拖动与编辑入口，个人备注继续独立保存。

## 公司十大事接口约定（待 Web/后端接入）

公司内容由有编辑权限的 Web 管理人员维护，安卓只读。当前安卓沿用 `GET /api/v1/panels/map` 的 `companyImportant`，字段为 `id,title,detail,sortOrder,myRemark`。后端当前未实现事项管理写接口，本次不调用不存在的写入路径。

预留 Web 管理端接口：

| 方法与路径 | 作用 | 请求/响应 |
| --- | --- | --- |
| `GET /api/v1/admin/company-priorities` | 读取可编辑清单与版本 | `{version,items:[{id,title,detail,sortOrder}]}` |
| `PUT /api/v1/admin/company-priorities` | 管理员保存完整清单及顺序 | 请求 `{expectedVersion,items:[...]}`；成功返回新版本和规范化清单 |

最多 10 条，标题 1～120 字，说明最多 2000 字；新项目不传 ID，由服务端分配，排序从 0 连续编号。服务端必须校验 token、公司归属和公司事项编辑授权，不以客户端显示的身份决定权限。未登录 401、无权限 403、输入非法 400、版本冲突 409；冲突时 Web 保留草稿并要求人工合并，不能覆盖他人发布内容。公司原文与员工个人备注分离。以上为预留契约，不能视为已经上线的管理能力。
