# 按键反馈与黑色描边（0.5.6）

2026-10-17；versionCode 40。仅安卓界面修改。

## 声音与触感

原音频 75ms，峰值仅 0.233，播放增益为 0.22，且使用系统界面音量通道；部分文字按钮没有反馈。现提高音频样本增益 2 倍，峰值 0.466，无削波；播放增益改为 0.65，通过媒体音量控制，Activity 音量键也控制媒体。保留静音/振动模式禁音与应用声音开关，不擅自修改系统音量。

触感由 KEYBOARD_TAP 改为 VIRTUAL_KEY，采用系统触摸反馈并遵循系统设置，不申请额外震动权限。按钮与文字操作共用反馈；日历已有反馈调用去重。启用单个开关时即时体验该项反馈。“我的 → 操作偏好”添加“试听声音与触感”，按当前开关试听；两项都关闭时禁用。

真机使用：打开应用按键声音和按键触感，手机处于正常铃声模式，适当提高媒体音量；检查蓝牙音频是否输出到耳机。无震感时开启手机系统触摸反馈。模拟器只能确认入口、开关与调用路径，不能证明特定手机的实际听感和震感。

## 黑色边界

浅色主题中的白色总览/职能面板、事项卡片、日历安排、日历控制按钮、次要页头按钮、输入框及弹窗使用细黑边。面板边框 1dp，保留既有圆角和紧凑间距。深色主题维持原有边界配色。黑色轮廓色由浅色主题统一提供，实心白色 Surface 显式加边框。

## 验证

Android 构建通过，30 项单元测试通过。音频为 22050Hz、16 位单声道 PCM，75ms，无削波。原生模拟器确认试听入口、两项开关可操作且持久化，所有验收页面无崩溃；查看总览、职能、个人事项、日历黑色边框截图。OpenSpec 变更与 6 个主规范严格校验通过。
