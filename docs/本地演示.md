# 本地日志 MVP 演示

演示目标：Android 员工登录 → 保存草稿 → 提交 → 首页/日视图查看 → 领导 Web 查看 → 员工修改 → Web 刷新看到最新内容。Web 也能编辑管理者自己的日志。

## 启动与安装

1. 仓库根目录双击 `start-demo.cmd`，保持窗口打开。电脑浏览器访问 http://localhost:8080，Ctrl+C 停止服务。
2. 将 `deliverables/Pandora-MVP-debug.apk` 传到手机并安装，应用名“潘多拉 MVP”，最低 Android 8。
3. 手机和电脑连同一局域网。应用登录页的服务地址填写启动器显示的 `http://电脑IPv4:8080`，不要填手机的 `localhost`。Android 官方模拟器用 `http://10.0.2.2:8080`。

首次启动需要联网下载依赖，电脑需要 Java 17+、Node 18+、Maven（支持 IDEA 附带 Maven）。数据在 `backend/data/`，不要删除。

```powershell
.\scripts\Start-Demo.ps1
# 改端口时，手机地址也改为相同端口
.\scripts\Start-Demo.ps1 -Port 8081
# 已构建且源码没有修改时
.\scripts\Start-Demo.ps1 -SkipBuild
```

## 三分钟演示

1. Android 用 `staff` 登录，新建今天的日志，填“完成登录接口联调”，保存草稿。
2. Web 用 `leader` 登录，选择“员工小王”，日期留空，刷新；草稿应不可见。
3. Android 打开该草稿并提交。首页右下日志板块、日视图和列表应出现同一条内容；Web 刷新后也能看到。
4. Android 编辑这条已提交日志，改为“完成三端日志联调”，保存。Web 刷新并选中该条记录，应显示新内容，日志 ID 不变。
5. Android 切换过去日期，应只显示该日记录；回到今天继续查看。Web 的“我的日志”可保存、提交和修改领导自己的记录。

不方便用手机时，可用 `scripts/Invoke-EmployeeDemo.ps1` 演示员工接口，参数见脚本帮助。

## 你手动确认

- 安装后能打开，按钮、返回、日期选择及旋转屏幕正常，文字不遮挡。
- 同 Wi-Fi 能登录并完成上述流程；连接失败时检查电脑 IPv4、端口和 Windows 防火墙，必要时允许该演示端口进入。
- 写入内容后暂时停止后端再保存，应提示失败且保留输入；恢复服务再保存，或关闭重开应用，同账号能恢复待保存内容。
- 重启服务和应用后，已保存日志仍可查到；Web 刷新仍能显示最新内容。
