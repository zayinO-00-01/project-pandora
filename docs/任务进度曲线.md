# 安卓任务工作进度

版本：0.5.8-task-progress（versionCode 42）。开发与交付目录：`C:/Users/adwe2/Desktop/project-pandora`。

安装 [APK](../deliverables/Pandora-0.5.8-task-progress-debug.apk)，进入「职能 → 任务 → 任务详情」。

## 界面与数据

- 以平滑曲线呈现「待开始 → 进行中 → 已完成」，青绿色实线表示已到达阶段，虚线表示后续阶段，铜色圆点标记当前阶段。
- 入场曲线约 900ms 展开；系统关闭动画时直接呈现。使用原生 Compose Canvas/Animatable，适配浅色、深色及小屏幕，并提供无障碍阶段说明。
- 展示接口返回的派发时间、最近更新时间和最新进度说明；责任人继续使用现有「反馈工作进度」提交状态，保存成功后图表使用返回数据。
- 当前接口只有最新状态与说明，没有历史变更记录。图中三个位置是工作阶段，不是完成百分比或时间轴，不补造历史进度、里程碑日期。
- 状态无法识别时显示「状态待同步」，不冒充正常阶段。更新失败沿用现有错误提示和输入保留机制。

## 实现选择

用户明确选择安卓任务详情原生实现。视觉参考 [Simple Graph](https://pro.reactbits.dev/docs/components/simple-graph) 的平滑曲线、渐变和描线动画；没有复制付费源码或安装 React 组件。安卓工程不是 React 项目，因此无需 components.json、shadcn 或 React Bits 授权密钥，也没有新增运行时依赖。原版安装要求见 [官方安装文档](https://pro.reactbits.dev/docs/installation)。

主要文件：`android/app/src/main/java/com/projectpandora/app/ui/TaskProgressGraph.kt`、`TaskScreen.kt`。
