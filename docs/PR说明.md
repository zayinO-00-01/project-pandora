# PR 标题

feat: deliver Pandora workspace, month calendar and organization access

## 改动说明

交付可构建的原生 Android 工作区、Web/后端日志与任务闭环，并将 Android 更新至 `0.4.25-role-access`。登录采用固定纸墨背景，工作区使用同一视觉资源，提供用户手动选择的浅色/深色模式；日历仅保留月历与日期记录标记。

员工、组长、部门负责人和公司负责人分别展示个人、团队、部门与公司工作入口。高级用户只能查看组织关系范围内的下级；向上仅可申请查看直属上级，由直属上级批准、拒绝或撤销。授权仅开放已提交日志和只读任务信息，草稿仍仅本人可见；组织关系改变会使原授权失效。包含 V4 数据库迁移与接口说明。

同步启动脚本、Gradle Wrapper、字体许可证、设计说明和验收资料；安装包、历史大体积媒体与机器本地数据不进入源码提交。
