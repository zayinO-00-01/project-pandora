# 本周功能与验收（2026-11-12）

当前版本：Android `0.10.6-company-calendar`（69）及配套后端、Web。已完成本地打包并部署云端，源码发布到 `zayin` 分支；结果见[云端发布记录](云端发布-2026-11-13.md)。

## 本周功能

| 内容 | 本版行为 |
| --- | --- |
| 首页 | 使用“首页”“公司”名称；首页包括“事件纪”“任务看板”“每日事项”，移除首页的个人十大和日志板块。原日志入口及历史数据保留。 |
| 任务看板 | 显示分配给本人的有效任务；“全部任务”放在公司页通讯录旁，保留本人创建或负责的任务范围。 |
| 通讯录 | 展示公司业务联系人，支持姓名、账号、电话搜索和本机星标。按权限查看全部层级下属的已提交日志、任务；不公开草稿及敏感人事字段。 |
| 日志月历 | 显示标签颜色、日志数量和任务数量。选择日期后列出当天全部本人任务及日志，支持点击查看。旧版跨日日志继续覆盖对应日期。 |
| 每日事项 | 独立的私人待办，按日期添加、修改、勾选完成和删除；保存到后端，可刷新和重试，删除前确认。退出或切换账号后不保留上个会话的编辑窗口及请求状态。上级和管理员不能读取别人的事项。 |
| 本人档案 | 本人可修改姓名、电话、紧急联系人、紧急电话、地址。身份证、生日、性别、入职日期、角色和组织关系仍由管理员维护。 |
| 节假日 | 内置2026年放假和调休上班标记；其他年份保留节日名称计算，未核实的未来放假、调休安排不作为正式标记显示。 |

保留原有效规则：日志限今天、昨天、前天创建，每人每天一篇（包括草稿），创建后24小时内可改/提交；任务创建时截止日期不得早于上海当天，开始时间可以在今天之前或之后，但不能晚于截止时间。原任务审核、本人备注、通知和停用标签兼容规则保留。

数十个账号按本次要求暂不录入。工作日志草稿删除未纳入本轮。

## 手机手动验收

使用本版APK连接新版云端 `http://39.107.204.229` 即可验收。也可以连接配套本地后端：模拟器使用宿主机地址，实体手机使用同网电脑IP或手机热点。

1. 查看首页的事件纪、本人任务看板和每日事项；进入公司页确认通讯录与全部任务的位置。
2. 用部门负责人查看跨一层的下属日志、任务；员工只能看到联系人资料，不能查看无授权同事的工作记录。
3. 日志页切换月历，检查标签颜色、同日多个任务提示；选择日期，确认下面可看到当天所有任务和日志。尝试年月直选。
4. 每日事项同一天添加至少三条，修改一条、勾选一条完成、取消一次删除再确认删除。刷新和重新登录后检查保存结果；换账号确认看不到之前的事项。
5. 打开每日事项编辑窗口后切换账号，确认窗口、输入和错误提示不会带到新账号。断网保存应提示失败并保留输入，联网后可重试。
6. 修改本人五项个人资料，保存后检查姓名、电话；重新登录确认持久化。检查没有修改角色及组织关系的入口。
7. 年月选择跳到2026年2月，检查15—23日休假和14日、28日调休上班；检查其他日历中的节日提示。未来年份的调休安排仍需核实后补入。
8. 简单回归：新建任务不能选昨天截止，允许历史开始日期；日志每天一篇及24小时窗口、授权通知跳转、原任务审核仍正常。
