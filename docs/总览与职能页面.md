# 总览与职能页面（0.5.4）

2026-10-17，versionCode 38。基于当前 0.5.3 工作区继续修改，保留已有真实派发、三天补录规则、公司与个人本机事项、成员授权和开发入口。本次不修改后端或 Web。

## 总览

只显示公司十大事、公司派发任务、个人十大事三个区块。公司十大事优先展示 3 条标题及两行说明，基础最小高度 248dp；公司派发展示 2 条任务，最小 168dp；个人重点展示 2 条紧凑标题，最小 112dp。实际内容可撑高并自然滚动；空态也保持主次。日志、待处理任务、组织成员入口移出总览，各板块可进入完整详情。

## 职能

底部顺序固定为：**总览 → 职能 → 日志 → 视图 → 我的**。

- 创始人／部门老总／团队长／旧版领导：主要区块是任务派发与本人已派发任务，使用已有派发表单、授权责任人列表和真实任务 API；人员区块较小，按角色进入公司组织、部门成员或团队成员。
- 普通员工：主要区块是本人待开始／进行中的任务，次要区块是查看直属上级；不显示派发按钮。已完成任务仍可在全部任务查看。
- 任务列表、任务详情、派发表单及组织页均属于职能流程；组织列表、完整任务列表返回职能，详情返回各自列表；临时离开不会清除任务派发和反馈草稿。

## 成员搜索

公司与个人十大事页取消事项搜索框。姓名搜索框位于 **职能 → 部门成员（或公司组织／团队成员）**。支持姓名或账号、清空、匹配数量与无结果提示，仅过滤服务器已授权成员，不扩展权限。普通员工的上级查看保留申请及获批后的只读机制。

## 月历
