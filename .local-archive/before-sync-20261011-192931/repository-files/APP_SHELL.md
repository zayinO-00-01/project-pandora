# Pandora App Shell

## Mobile

```text
system safe area
page toolbar when needed
scrollable workspace
stable bottom navigation
```

Primary navigation: 首页、视图、日志、分析、我的。

High-frequency actions belong in the page toolbar or the first workspace section. Do not add a second competing navigation system inside a page.

## Desktop target

When desktop support is added, keep one shared shell:

```text
Global Sidebar | optional secondary navigation | Main Workspace
```

The shell owns search, notifications, user menu, breadcrumbs, and workspace switching. Pages own their toolbar and business content.
